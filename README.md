# 守秘人笔记本

一个本地运行的 CoC KP 备本工作台。它把文字模组整理成可翻阅、可编辑、可追溯原文的模组笔记本，并提供人物关系、幕结构和调查员图片资料包。

## 当前版本

v1.0.0 包含：

- 导入带文字层的 PDF、DOCX 和 Markdown
- 浏览器本地项目库与原文件保存
- 自动识别并人工确认章节
- OpenAI、Anthropic、Gemini 与 Ollama 模型协议
- 七阶段生成故事背景、时间地点、人物、怪物/Boss、人物经历、线索和幕
- 区分原作事实、AI 推断、KP 修改和原作矛盾
- H1–H6 Markdown 可视化编辑、目录跳转和 turn.js 双页翻页
- 人物、怪物、地点、线索、事件等实体资料卡与语义关系
- 核心人物关系图、个人关系图和 KP 关系覆盖
- 图片为主页面与外部资料依赖提醒
- PDF/DOCX 原文对照、图片提取和调查员资料包
- 实时确认、阶段重试和分析历史

API Key 默认只保存在浏览器会话中；用户明确启用“记住凭据”后才写入本地持久存储。

## 运行

需要 Node.js 22.13 或更高版本。

```powershell
npm install
npm run dev
```

浏览器会通过本机地址访问应用：

```text
http://localhost:3000
```

## 验证

```powershell
npm run build
npm run lint
npm run test
```

## 数据与隐私

项目数据和导入的原文件保存在浏览器 IndexedDB 中，不会上传到本项目的服务器。执行 AI 分析时，用户勾选章节的文字会发送到其自行配置的模型服务商。

本地模型代理仅接受 HTTPS 地址；`localhost` 和 `127.0.0.1` 可使用 HTTP。
