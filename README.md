# 守秘人图谱

一个本地运行的 COC KP 备本工作台。它把文字模组整理成可以核对的幕后真相、人物关系图和分支时间线，并让重要结论跳回 PDF 原文。

## 当前版本

V0.1 已包含：

- 导入带文字层的 PDF、DOCX 和 Markdown
- 浏览器本地项目库与原文件保存
- 自动识别并人工确认章节
- OpenAI Chat Completions 兼容接口，可配置 Kimi 等服务
- 分阶段生成故事概览、人物、关系和分支时间线
- 区分原作事实、AI 推断、KP 修改和原作矛盾
- 人物别名合并确认
- 图片为主页面与外部资料依赖提醒
- PDF 页码引用和原文对照
- 人物、事件的手动修订

当前开发版的 API Key 只保存在浏览器会话中，关闭浏览器后需要重新填写。

## 运行

需要 Node.js 22.13 或更高版本。

```powershell
npm install
npm run dev
```

浏览器会通过本机地址访问应用：

```text
http://localhost:3000
```

## 验证

```powershell
npm run build
npm test
```

## 数据与隐私

项目数据和导入的原文件保存在浏览器 IndexedDB 中，不会上传到本项目的服务器。执行 AI 分析时，用户勾选章节的文字会发送到其自行配置的模型服务商。

本地模型代理仅接受 HTTPS 地址；`localhost` 和 `127.0.0.1` 可使用 HTTP。
