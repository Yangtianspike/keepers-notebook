# 守秘人图谱 v0.2 开发计划

## 版本目标

v0.2 从“能生成备本的原型”升级为“KP 可持续核对、编辑和组织信息的备本工作台”。

本版本优先完成三项能力：

1. 可用的人物关系画布。
2. 流式分析与 KP 确认闸门。
3. 线索网络分析模块。

## 已启动：人物关系画布

- 使用 React Flow 替换旧的自定义关系图。
- 自动布局、缩放、平移、拖拽人物卡。
- 连线连接到人物卡边缘，显示箭头；关系标签放在箭头前的末段连线上。
- 单一关系图中以绿色表示 KP 已知关系、蓝色表示公开人物关系；AI 推断仍以虚线提示。
- 已完成：拖拽布局自动保存、点击关系线跳转 PDF。
- 待定（暂不纳入 v0.2 当前开发）：组织分组、人物聚焦一层/两层/全图。

## 流式分析与 KP 确认闸门

### 页面与工作方式

- 直接升级现有“分析流程”页面，不建立独立工作台页面。
- 页面同时显示阶段进度、实时工作日志和右侧确认栏。
- KP 可手动暂停；遇到关键待确认事项时自动暂停。
- 多项待确认按严重度排队：原作矛盾、人物合并、推断关系。

### KP 确认

- KP 可接受、拒绝或编辑结论、理由、原文依据和页码。
- KP 修改版直接作为有效版本和后续分析上下文。
- 推断关系需要 KP 点击“应用到关系图”后才正式加入。
- 原作矛盾支持填写“本团采用的解释”，后续分析按此解释继续。
- 外部资料依赖只记录，不打断分析。

### 保存与恢复

- 流式内容每次追加后自动保存。
- 优先从断点继续；模型服务不支持可靠续写时，回退到最近完成阶段。
- 暂不保留 AI 原始版本与 KP 修改版本的双版本对照。

### 当前实现说明

- 已实现 OpenAI 兼容 SSE 流式输出、分析流程实时预览、分析记录和流程内确认队列。
- 已实现 KP 手动暂停；暂停会保存为阶段状态，恢复时重新运行该阶段。
- 已实现确认结果注入后续模型上下文。
- 受通用 Chat Completions 协议限制，当前不承诺从模型输出的“令牌级断点”续写；使用可靠的阶段级恢复方案。

## 新模块：线索网络

### 模块位置与运行方式

- 左侧导航位置：分支时间线之后、待确认之前。
- 分析流程中作为第 04 步。
- 除人物与关系内部有先后顺序外，线索网络和其他模块均可独立分析、独立重新分析。

### 线索信息

- 每条线索包含名称、内容摘要、来源地点/场景、主要/次要指向、获得条件、错过条件和 KP 补救建议。
- 指向目标分为人物、地点、事件、真相四类。
- KP 可手动新增完整线索，最少填写名称、来源和主要指向；新增后立即加入网络，标记“KP 手动添加”。
- 默认显示简短原文依据摘要；可点击跳转 PDF。

### 调查路径与风险

- AI 初步标记关键 / 次要 / 其他，KP 可改。
- 线索可存在主要指向与次要指向。
- 显示调查路径和替代线索路径。
- 标记无替代入口、依赖特定技能/NPC/时机的卡关风险，说明原因。
- 补救建议可来自原作替代线索、AI 无剧透建议和 KP 自己的方案。
- KP 编辑线索后不自动重算路径，保留当前人工整理结果。

### 真相节点与视图

- AI 归纳的真相节点先进入待确认；KP 接受后才加入网络。
- 网络图中线索、人物、地点、事件、真相使用不同节点形状。
- 连线显示指向、揭示、通往、可替代等动作。
- 默认展示关键线索与关键真相的精简网络；可切换全图与清单。网络节点和清单卡均可打开编辑。
- 表格支持按关键程度、地点/场景、时间顺序排序。
- 工具仅面向 KP，不提供玩家无剧透视图。

## 当前版本边界

- 暂不做导出功能。
- 暂不做独立地点与场景分析模块；线索的地点/场景先以 AI 从原文识别的名称记录。
- 暂不接入调查员角色卡和跑团中的实际发现状态。

## 2026-07-30 验收调整

- 分支时间线移除横向模式，统一为 React Flow 纵向画布：主线自上而下，分支从对应主线事件向侧方展开，并使用带箭头的边。
- 线索卡编辑保留为独立表单，避免在画布拖拽时误改内容；网络节点的“编辑”和清单卡的“编辑线索”（或双击清单卡）均会打开该表单。
