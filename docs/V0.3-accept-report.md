## 七、验证过程中发现的方法论问题

1. **PowerShell JSON 转义陷阱**：单引号字符串内的 `\"` 会被当作字面反斜杠+引号发送，导致 `/api/model` 收到非法 JSON 返回 500。一度误判为代码 bug，改用 `ConvertTo-Json` 后确认为测试方法错误。已修正。
2. **测试断言疏忽**：`normalizeQuote` 先 `toLowerCase`，全角 `ＡＢＣ` 转半角后是小写 `abc`；初版断言写成 `ABC` 导致失败。修正后 24/24 通过。说明引用校验是大小写不敏感的（合理设计）。
