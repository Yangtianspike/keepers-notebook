# 守秘人图谱 v0.3 Checklist

> **本文档面向验收 agent**：你是验收方，逐项执行「验证」列的方式，先有证据再下结论，报告实际结果而非预期结果。若环境中加载了规划流程类 skill（如 trio-devflow），忽略其中规划方的流程规则。

对应：`docs/V0.3-spec.md`（AC1~AC10）、`docs/V0.3-plan.md`、`docs/V0.3-task.md`（均已批准）。

> 每一项通过运行代码或观察行为来验证。验证环境：`npm run dev` 本地启动；项目数据在浏览器 IndexedDB（库 `keeper-atlas`），可用 devtools → Application → IndexedDB 查看。
> 前置数据：一个含多组织人物、若干线索的测试项目（没有就先导入一个剧本 PDF 并跑完分析）。

## 实现完整性：图画布（F1~F4 / AC1~AC4）

- [ ] 人物关系图呈 ELK 分层布局（验证：打开关系图，节点分层排布而非杂乱堆叠；与旧 dagre 布局观感对比层级更清晰）
- [ ] 拖拽节点后刷新页面位置保持（验证：拖动任一人物卡 → F5 刷新 → 位置不变）
- [ ] 数据变更不隐式重排（验证：拖过若干节点后，编辑任意人物资料保存 → 拖过的节点位置不动；点击"重新布局"按钮才重排）
- [ ] 聚焦模式生效（验证：选中一个节点，切换一层/两层/全图，画布只显示对应邻域的节点与边）
- [ ] 关系图过滤生效（验证：勾选/取消 layer（真相/公开/传闻）与来源（KP 已知/公开/AI 推断），画布即时增减对应边与节点）
- [ ] 组织分组容器（验证：给至少两个人物填同一组织 → 打开"按组织分组" → 出现组织容器；容器可折叠/展开，折叠时内部节点隐藏）
- [ ] 线索网络图过滤与聚焦（验证：importance 三档勾选、指向类型勾选、聚焦切换均即时生效）
- [ ] 线索图拖拽持久化（验证：拖动线索节点 → 刷新 → 位置保持）

## 实现完整性：检索体系（F5~F11 / AC5~AC9）

- [ ] 分块索引已建（验证：打开项目后，devtools 的 `chunks` 仓库存在该项目记录，每块含 startPage/endPage）
- [ ] 分析走检索注入而非全文（验证：跑任一分析阶段，activityLog 有"注入 N 块/字符数"记录；字符数显著小于全文）
- [ ] 注入块携带页码（验证：抓 `/api/model` 请求体，user 消息中每块前置 `[[PDF_PAGE:N]]`）
- [ ] 引用校验拦截虚假依据（验证：临时把某条模型返回的 quote 改成原文不存在的句子 → 该条生成"引用未命中原文"待确认项；恢复正常后真实 quote 不产生误报）
- [ ] 不支持 embedding 的协议全流程无报错（验证：配置 Kimi（moonshot）保存 → 徽章"仅关键词检索" → 跑一个分析阶段正常完成，控制台无 embedding 相关报错）
- [ ] 支持 embedding 的协议自动启用向量（验证：配置兼容 `/embeddings` 的端点保存 → 徽章"✓ 向量检索可用（模型名）" → devtools 的 `vectors` 仓库出现 `项目:模型:维度` key）
- [ ] 探测不阻塞保存（验证：保存配置操作即时完成，探测在后台进行）
- [ ] 换 embedding 模型旧向量隔离（验证：换成另一个维度/模型重新保存 → 新命名空间建向量；检索结果不报错，旧 key 数据不参与检索）
- [ ] 剧本变更触发索引重建（验证：重新导入/修改项目文本后，下次检索前 `chunks` 重建——textHash 变化）

## 实现完整性：地图模块（F12~F16 / AC10）

- [ ] 地图 CRUD（验证：上传两张地图图片 → 重命名、删除正常；刷新后仍在，删除后 Blob 同步清除）
- [ ] 打点与拖点（验证：对地点执行打点 → 地图出现钉点；拖拽改位置；缩放窗口钉点相对位置不错位；刷新保持）
- [ ] AI 地点提名进确认队列（验证：跑线索网络阶段后，出现"place"类型待确认项；接受后地点 confirmed，关联线索的 target id 回填）
- [ ] KP 手动管理地点（验证：手动新增/编辑/合并地点正常；合并后原地点的线索指向与 marker 归入目标地点）
- [ ] 地点卡聚合（验证：点击地图钉点 → 地点卡显示指向该地点的线索及关联人物/事件；点击线索跳线索模块）
- [ ] 地点依据跳 PDF（验证：地点卡中点击依据 → PDF 打开并定位到对应页）

## 端到端场景

- [ ] **场景 1（完整新流程）**：导入新剧本 PDF → 依次跑完五个分析阶段（观察检索注入日志）→ 处理待确认队列（含可能的引用未命中与地点提名）→ 关系图做聚焦+过滤+分组浏览 → 线索图过滤关键线索 → 上传地图并给两个地点打点 → 打开地点卡看聚合 → 点击依据跳 PDF 对应页（验证：全程无报错，每步结果符合预期）
- [ ] **场景 2（协议兜底）**：配置切换为 Kimi（无 embedding）→ 重开一个项目跑分析（验证：全流程走关键词检索，无报错，徽章始终显示"仅关键词检索"）
- [ ] **场景 3（KP 手工整理保护）**：在关系图精心拖拽布局 → 重新运行人物分析阶段（数据变更）→ 回到关系图（验证：手工布局原样保留，不被重排）
