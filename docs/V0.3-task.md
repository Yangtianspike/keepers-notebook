## T4: 分块与 BM25

**文件：** `lib/retrieval.ts`（新建）
**依赖：** T2
**步骤：**
1. `buildChunks(pages, projectId)`：按页顺序拼接文本，约 500 字切块、相邻重叠约 50 字，记录每块 `startPage`/`endPage`；跳过 `imageHeavy` 且文本 <100 字的页内容（页码仍计入区间）
2. `hashPages(pages)`：简单字符串散列（如 FNV-1a）生成 `textHash`
3. `tokenize(text)`：中文二字滑窗 + 连续字母数字整词
4. `bm25Search(chunks, query, k)`：标准 BM25（k1=1.5，b=0.75），返回 `[{ chunk, score }]` 降序

**验证：** `npx tsc --noEmit` 通过；在 dev 控制台对测试项目跑 `buildChunks` + `bm25Search`，常见词（如人物名）能召回所在页块

**依赖：** 无
