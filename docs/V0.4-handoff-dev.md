## 背景

v0.4 已由上一个开发 agent 实现完成（commit `c2e682a` 及之前），但用户验收后发现两个问题需要补丁修复：

1. **确认队列架构偏差**：当前实现是"阶段后阻塞"（阶段跑完才弹窗），用户要求的是"实时确认"（模型遇到冲突立即暂停弹窗）。需要引入协议适配层，支持三档模型能力（Tier 1 function calling / Tier 2 JSON 块 / Tier 3 阶段后阻塞）。
2. **UI 风格回退**：v0.4 已实施的书卷风格（commit `4a54dcf` + `da8112b`）需要 revert，恢复 v0.3 暗色现代 UI。做旧风格推迟到后续版本。

## 项目速览

- 本地启动：`npm run dev`（Node >= 22.13），注意服务绑定 IPv6 `[::1]:3000`，浏览器访问 `http://[::1]:3000/`

- 分析流程已经是分阶段 HTTP 调用（每次 POST `/api/model` 传一个 stage），`route.ts` 的 `analyze` 返回 JSON
- 当前 `DB_VERSION = 3`（v0.4 已升级）
