## 十一、端到端场景

### 场景 1：地图融合完整流程（需真实 API Key + 含地图图片的 PDF）

1. 导入含地图图片和方位描述的剧本 PDF → 跑分析
2. 分析完成 → 打开地图页签 → 地图画布显示
3. 地点节点按 AI 文本方位解析的坐标摆放（①）
4. 点"提取 PDF 图片" → 图片提取成功 → 选择一张作为底图（②）
5. 在图片上打点调整地点位置
6. 配置 Qwen-VL 视觉模型 → 点"视觉识别" → 坐标自动识别（③）
7. 点击地点节点 → 就地展开 → 显示关联人物/线索
8. 拖拽未关联人物到地点 → 挂载成功
9. 刷新页面 → 位置和挂载关系保持

**预期结果**：全程无报错，三档坐标都可用，挂载关系持久化。

### 场景 2：UX 修复验证

1. 跑人物分析（Tier 1 实时确认）→ 模型遇到冲突弹窗
2. 点"接受并继续" → 弹窗立即关闭 → loading 显示
3. 等待请求完成 → 如果有新冲突重新弹窗，否则进入下一阶段
4. 不再出现弹窗卡死 30 秒的问题

**预期结果**：弹窗即时关闭，loading 状态正确，流程顺畅。

### 场景 3：降级兼容

1. 不配视觉模型 → "视觉识别"按钮禁用
2. 不选 PDF 图片底图 → 画布为抽象画布，地点按 AI 坐标摆放
3. 全部功能仍可用（①文本坐标 + ②手动打点）

**预期结果**：降级正常，核心功能不受影响。
