## 关键注意事项

1. **数据类型先行**：T1 先改 `lib/types.ts` 和 `lib/model-adapter.ts`，后续任务都依赖类型定义
2. **PDF 图片提取**：用 `pdfjs.getPage().getOperatorList()` 筛选 `OPS.paintImage`，用 canvas 渲染为 base64。注意 `ImageData.kind` 可能需要色彩空间转换
3. **视觉模型走 OpenAI vision 格式**：`content` 改为数组 `[{type:"text",text:...}, {type:"image_url",image_url:{url:...}}]`，Qwen-VL/GLM-4V/GPT-4o 都兼容
4. **地图画布复用 React Flow**：已有 `@xyflow/react` 依赖，参考 `atlas-map.tsx` 的代码结构
5. **地点坐标三档独立实现**：①AI文本解析（改 prompt）②PDF图片+手动打点 ③视觉模型识别。③没配视觉模型时按钮禁用
6. **UX 修复改动最小**：只改 `continueRealtimeAnalysis` 的顺序——先关弹窗+设 loading，再 fetch。不要动其他逻辑
7. **章节总结只定义类型**：`ChapterSummary` 类型加入 `types.ts`，但不写生成逻辑和 UI
8. **旧项目兼容**：新字段默认空数组/undefined，`emptyAnalysis` 中设默认值，不需要 DB 迁移
