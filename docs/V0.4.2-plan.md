# 守秘人图谱 v0.4.2 技术设计（Plan）

对应：`docs/V0.4.2-spec.md`（已批准）。

---

## 一、架构原则

1. **地图画布复用 React Flow**：项目已有 `@xyflow/react` 依赖，`atlas-map.tsx` 组件代码完整（v0.4 隐藏未用），v0.4.2 复用并改造为"地点节点+人物/线索挂载"模式。
2. **PDF 图片提取用 pdfjs 原生 API**：`page.getOperatorList()` 获取绘制操作，筛选图片操作后用 canvas 渲染为 base64。不引入新依赖。
3. **视觉模型走 OpenAI 兼容格式**：`ModelMessage.content` 扩展为数组格式（支持 `image_url`），复用现有 `/api/model` 路由，新增 `action: "vision"`。
4. **章节总结只定义数据结构**：v0.4.2 不实现生成流程和 UI，只定义 `ChapterSummary` 类型，为后续版本预留。
5. **UX 修复改动最小**：只调整 `continueRealtimeAnalysis` 的响应处理顺序，在 fetch 前关闭弹窗。

## 六、PDF 图片提取

### `lib/pdf-images.ts`

```typescript
export async function extractPdfImages(
  file: File,
  onProgress?: (page: number, total: number) => void
): Promise<MapImage[]> {
  const pdfjs = await import("pdfjs-dist/legacy/build/pdf.mjs");
  const data = new Uint8Array(await file.arrayBuffer());
  const document = await pdfjs.getDocument({ data }).promise;
  const images: MapImage[] = [];

  for (let pageNumber = 1; pageNumber <= document.numPages; pageNumber++) {
    const page = await document.getPage(pageNumber);
    const operatorList = await page.getOperatorList();
    const viewport = page.getViewport({ scale: 1 });

    // 遍历操作列表，筛选图片
    for (let i = 0; i < operatorList.fnArray.length; i++) {
      const fn = operatorList.fnArray[i];
      if (fn === pdfjs.OPS.paintImage) {
        const args = operatorList.argsArray[i];
        const imgData = args[0]; // ImageData 对象
        // 用 canvas 渲染为 base64
        const canvas = document.createElement("canvas");
        canvas.width = imgData.width;
        canvas.height = imgData.height;
        const ctx = canvas.getContext("2d");
        ctx.putImageData(imgData, 0, 0);
        const base64 = canvas.toDataURL("image/png");
        images.push({
          id: crypto.randomUUID(),
          page: pageNumber,
          base64,
          width: imgData.width,
          height: imgData.height,
          selectedAsMap: false,
        });
      }
    }
    onProgress?.(pageNumber, document.numPages);
  }
  return images;
}
```

### 注意事项

- `paintImage` 的 `args[0]` 是 `ImageData`，但某些 PDF 可能用 JPEG 压缩，需要检查 `imgData.kind` 并转换
- 大 PDF 可能有很多图片，需要进度提示
- 图片过大时压缩（限制最大 1024×1024）

## 七、视觉模型适配

### `lib/vision-adapter.ts`

```typescript
export function buildVisionRequest(
  imageBase64: string,
  placeNames: string[],
  visionModel: string
): Record<string, unknown> {
  return {
    model: visionModel,
    temperature: 0.1,
    max_tokens: 2000,
    messages: [
      {
        role: "user",
        content: [
          {
            type: "text",
            text: `这是一张地图图片。请识别图上以下地点的位置，返回 JSON 数组，每个元素包含 name（地点名）、x（0-1000 横坐标）、y（0-1000 纵坐标）。地点列表：${placeNames.join("、")}`,
          },
          {
            type: "image_url",
            image_url: { url: imageBase64 },
          },
        ],
      },
    ],
  };
}

export function parseVisionResponse(raw: unknown): Array<{ name: string; x: number; y: number }> {
  // 解析视觉模型返回的 JSON 数组
  const content = (raw as any)?.choices?.[0]?.message?.content;
  // 提取 JSON 数组
  const match = content.match(/\[[\s\S]*\]/);
  if (!match) return [];
  return JSON.parse(match[0]);
}
```

## 十、风险与对策

| 风险 | 严重度 | 对策 |
|---|---|---|
| PDF 图片提取格式多样（JPEG/PNG/JBIG2） | 中 | 先支持常见格式，特殊格式跳过并记录日志 |
| 视觉模型 API 兼容性差异 | 中 | 用 OpenAI vision 格式（最通用），Qwen-VL/GLM-4V/GPT-4o 都兼容 |
| 地图画布性能（大量节点） | 低 | 地点通常 ≤50，React Flow 能处理 |
| 视觉模型识别准确率 | 中 | 识别后 KP 可手动微调坐标 |
| `ModelMessage.content` 类型扩展导致现有代码类型错误 | 高 | 用联合类型，现有纯文本代码不受影响 |
