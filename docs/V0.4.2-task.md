## T2: PDF 图片提取

**文件**：`lib/pdf-images.ts`（新建）
**依赖**：T1

**步骤**：
1. 实现 `extractPdfImages(file: File, onProgress?: (page, total) => void): Promise<MapImage[]>`
2. 用 `pdfjs.getPage().getOperatorList()` 获取操作列表
3. 遍历 `fnArray`，筛选 `OPS.paintImage` 操作
4. 用 canvas 将 `ImageData` 渲染为 base64（PNG 格式）
5. 图片过大时压缩（限制最大 1024×1024，用 canvas 缩放）
6. 跳过非图片操作，记录日志
7. 返回 `MapImage[]` 数组

**验证**：
- 用含图片的测试 PDF → 提取出图片数组 → 每张图有 base64/width/height/page
- 无图片的 PDF → 返回空数组，无报错

## T5: 地图画布组件

**文件**：`app/components/atlas-canvas.tsx`（新建）
**依赖**：T1, T2

**步骤**：
1. React Flow 画布，背景为抽象画布（无底图）或 PDF 图片底图
2. 地点节点（PlaceNode）：
   - 默认状态：显示地点名 + 小图标
   - 展开状态：地点名 + 周围关联人物/线索小节点
   - 可拖拽调整位置 → 更新 `Place.coordinates` → 存 IndexedDB
3. 就地展开逻辑：
   - 点击地点节点 → `expandedPlaceId` 设置 → 渲染关联小节点
   - 关联来源：`PlaceLink`（手动）+ `ClueTarget.type==="place"`（自动）
   - 点击小节点 → 触发 `onSelectPerson`/`onSelectClue` 回调
   - 点击空白 → 收回展开
4. 工具栏：
   - "提取 PDF 图片"按钮 → 调用 `extractPdfImages` → 存 `mapImages`
   - "选择地图底图"按钮 → 打开 `MapImagePicker`
   - "视觉识别"按钮（需配视觉模型）→ 调用 `action: "vision"`
   - "手动添加地点"按钮
5. 侧边列表：未关联人物/线索，可拖拽到地点节点上 → 创建 `PlaceLink`（source: "manual"）

**验证**：
- 渲染 mock 地点数据 → 节点显示在画布上 → 可拖拽 → 刷新后位置保持
- 点击节点 → 展开小节点 → 点击空白收回
- 拖拽人物到地点 → PlaceLink 创建

## T7: 地点坐标三档实现

**文件**：`app/api/model/route.ts`（place prompt）、`app/page.tsx`（视觉识别触发）、`lib/vision-adapter.ts`
**依赖**：T3, T5

**步骤**：
1. ①文本方位解析：
   - `route.ts` 的 clues 阶段 prompt 增加："如果文本描述了地点的相对方位，输出 `coordinates: {x, y}`，x/y 为 -100 到 100 的相对值"
   - `Place` 类型已有 `coordinates` 字段，模型输出后填入
2. ②PDF 图片提取+手动打点：
   - KP 选定图片底图后，在图片上点击 → 创建 `Place.coordinates`（source: "image_pin"）
   - 坐标为图片像素坐标（0~图片宽高）
3. ③多模态自动识别：
   - KP 点"视觉识别"按钮 → 调用 `action: "vision"`，传入选定图片 base64 + 地点名列表
   - 返回坐标 → 填入 `Place.coordinates`（source: "vision_model"）
   - 没配视觉模型 → 按钮禁用 + 提示"请在设置页配置视觉模型"

**验证**：
- ①分析含方位描述的剧本 → 地点有初始坐标
- ②选图片底图 → 点击图片打点 → 坐标存入
- ③配视觉模型 → 点视觉识别 → 坐标自动填入
- ③没配视觉模型 → 按钮禁用
