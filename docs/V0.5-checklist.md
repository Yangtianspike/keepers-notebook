## 十、端到端场景

### 场景 1：完整新流程（需真实 API Key + 测试剧本）

1. 导入剧本 PDF → 设置页选实时确认（Tier 1）→ 跑分析
2. 7 阶段顺序执行：故事背景→时间地点→核心人物（实时确认）→人物经历→开篇钩子→关键线索（实时确认）→幕
3. 幕生成后 → 章节总结自动生成
4. 打开"幕"页签 → 树状图显示所有幕和分支 → 点击节点 → 幕详情
5. 幕详情：人物卡分层/线索卡分层/分支/事件点（含 Boss 数值）
6. 打开"文档结构" → 查看章节总结 → 8 部分展示
7. 打开"幕后真相" → 6 部分全局结果

**预期结果**：全程无报错，7 阶段完成，幕和章节总结生成。

### 场景 2：旧项目迁移

1. 打开 v0.4 旧项目（含 relations/timeline/people/clues）
2. 无报错 → relations 迁移到 acts → timeline 迁移到 acts
3. 打开"幕"页签 → 迁移的幕显示
4. 其他数据（人物/线索）保留

**预期结果**：迁移正确，数据不丢失。

### 场景 3：UX 修复验证

1. 跑分析 → 核心人物阶段实时确认弹窗
2. 点"接受并继续" → 弹窗立即关闭 → loading
3. 请求完成 → 下一阶段或重新弹窗

**预期结果**：弹窗即时关闭，无 30 秒等待。
