## 项目速览

- 本地启动：`npm run dev`（Node >= 22.13），浏览器访问 `http://[::1]:3000/`
- 项目数据在浏览器 IndexedDB（库 `keeper-atlas`）
- Next.js + Tailwind CSS v4 + TypeScript，无 shadcn/ui
- `page.tsx` 约 4000+ 行，是主要工作文件
- 当前 `DB_VERSION = 3`（v0.5 升至 4）
- 分析流程已支持三档确认模式（tier1/tier2/tier3）

## v0.5 核心改动

1. 分析流程从 5 阶段重构为 7 阶段（故事背景/时间地点/核心人物/人物经历与动机/开篇钩子/关键线索安排/幕）
2. 砍掉 4 个模块：地图、人物门户、线索图、时间线
3. 新增"幕"模块（含分支树状图）
4. 章节总结实现生成和 UI
5. UX 修复（accept 弹窗即时关闭）
