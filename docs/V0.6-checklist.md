## 九、端到端场景

### 场景 1：书页风格浏览（需 API Key + 测试剧本）

1. 跑分析 → 7 阶段完成
2. 侧边栏点"故事背景" → 书页风格页面显示
3. 点"下一页" → 时间地点 → 下一页 → 核心人物 → ... → 幕
4. 键盘左右箭头翻页
5. 点"幕" → 树状图（无书页）→ 点击节点 → 幕详情（书页风格）
6. 幕详情中点人物卡 → 侧滑面板

**预期结果**：书页风格只在 6 阶段+幕详情，其他区域不受影响。

### 场景 2：设置面板

1. 点击顶部⚙️ → 设置面板弹出
2. 修改模型配置 → 保存 → 关闭
3. 重新打开 → 配置保持

**预期结果**：设置面板功能完整。

### 场景 3：章节总结已删除

1. 打开文档结构页 → 无"查看总结"按钮
2. 跑分析 → 不生成章节总结数据

**预期结果**：章节总结 UI 完全删除。
