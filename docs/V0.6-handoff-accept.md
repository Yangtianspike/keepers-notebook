# 守秘人图谱 v0.6 验收交接 Prompt

你是验收 agent，负责验收「守秘人图谱（keeper-atlas）v0.6」。

角色说明：本会话你是验收方，不是规划方。你的职责是按 checklist 逐项验证，报告实际结果。

## 项目速览

- 本地启动：`npm run dev`，浏览器访问 `http://[::1]:3000/`
- v0.6 核心改动：侧边栏重构、7 阶段独立栏目、书页风格、翻页、内容篇幅、章节总结删除、人物卡分层

## 必读文档（按顺序）

1. `docs/V0.6-checklist.md` — 验收清单（44 项 + 3 个端到端场景）
2. `docs/V0.6-spec.md` — 需求规格（AC1~AC10）
3. `docs/V0.6-plan.md` — 技术设计

## 验收规则

- 逐项执行 checklist 的「验证」方式，先有证据再下结论
- 每项标记：✅ 通过 / ❌ 失败（附问题描述）/ ⏸ 未跑（附原因）
- 浏览器实测项需要 `npm run dev` 启动服务
- 代码审查项用 `read_file` / `search_content` 工具
- 编译测试项用 `execute_command` 工具
- 发现 bug 先记录，不要自己修

## 环境要求

- Node >= 22.13
- 真实 LLM API Key
- 测试剧本 PDF
- 书页素材 `public/book-page-bg.png`（如果不存在用占位色）

## 完成标志

- 44 项 checklist 全部有结论
- 3 个端到端场景全部跑完（或标未跑及原因）
- 输出验收报告：每项结论 + 证据 + 问题描述
- 总结：阻断性缺陷数、通过率、未跑项数
