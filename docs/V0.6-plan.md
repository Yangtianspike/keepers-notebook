# 守秘人图谱 v0.6 技术设计（Plan）

对应：`docs/V0.6-spec.md`（已批准）。

---

## 一、架构原则

1. **侧边栏结构改造**：`navigation` 数组改为嵌套分组结构，`View` 类型扩展 7 个阶段视图。
2. **OverviewView 拆分**：当前 OverviewView 统一展示 6 阶段结果，拆分为 6 个独立 `StageView` 组件 + 共享书页风格容器。
3. **书页风格用 CSS 背景**：`public/book-page-bg.png` 作为内容区域背景，不影响菜单栏和顶部栏。
4. **翻页用状态管理**：`currentStageIndex` 状态 + 上一页/下一页按钮 + 键盘事件监听。
5. **章节总结只删不建**：删除 UI 和生成逻辑，保留类型。
6. **人物卡面板用模态/侧滑**：点击人物卡 → 弹出详情面板。

### 翻页逻辑

```typescript
const STAGE_VIEWS = [
  "stage-background", "stage-timeplace", "stage-characters",
  "stage-characterArcs", "stage-openingHook", "stage-clues", "acts"
];

const navigateStage = (direction: number) => {
  const currentIndex = STAGE_VIEWS.indexOf(view);
  const newIndex = currentIndex + direction;
  if (newIndex >= 0 && newIndex < STAGE_VIEWS.length) {
    setView(STAGE_VIEWS[newIndex]);
  }
};

// 键盘事件
useEffect(() => {
  const handleKey = (e: KeyboardEvent) => {
    if (!STAGE_VIEWS.includes(view)) return;
    if (e.key === "ArrowLeft") navigateStage(-1);
    if (e.key === "ArrowRight") navigateStage(1);
  };
  window.addEventListener("keydown", handleKey);
  return () => window.removeEventListener("keydown", handleKey);
}, [view]);
```

## 六、6 个阶段视图内容

每个阶段视图从 `project.analysis` 取数据，在 StageView 容器内渲染：

| 视图 | 数据 | 渲染 |
|---|---|---|
| stage-background | `analysis.overview` | oneLine 标题 + cause/history/currentState 段落 + plans 列表 + conflicts |
| stage-timeplace | `analysis.timePlace` | timeline 文本 + places 卡片列表 |
| stage-characters | `analysis.people` | 人物卡片网格（按 importance 分层） |
| stage-characterArcs | `analysis.characterArcs` | 每人 article（name/experience/motivation） |
| stage-openingHook | `analysis.openingHook` | 纯文本 |
| stage-clues | `analysis.clues` | 线索卡片网格（按 importance 分层） |

## 八、prompt 字数要求

### background 阶段

```
分析整个剧本的故事背景，提炼故事核心、起因、历史、当前状态和可能结局。
返回格式：
{
  "overview": {
    "oneLine": "一句话故事核心",
    "cause": "起因（100字左右）",
    "history": "历史（150字左右）",
    "currentState": "当前状态（100字左右）",
    ...
  }
}
```

### characterArcs 阶段

```
基于已确认的人物列表，逐一分析人物在故事中的经历、行动变化和深层动机。
返回格式：
{
  "characterArcs": [{
    "personId": "人物id",
    "experience": "经历概述（150-200字）",
    "motivation": "动机详解（100字左右）"
  }]
}
```
