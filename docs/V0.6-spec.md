# 守秘人图谱 v0.6 需求规格说明

## 版本目标

v0.6 聚焦 UI 重构：侧边栏分组 + 7 阶段独立栏目 + 书页风格 + 简单翻页 + 内容篇幅调整 + 章节总结 UI 删除 + 人物卡分层显示。

---

## 一、功能需求

### F1. 侧边栏重构

**F1.1 两组分类**

```
[前期准备]
  项目仪表盘
  文档结构
  分析流程
[剧本解析]
  故事背景
  时间地点
  核心人物
  人物经历与动机
  开篇钩子
  关键线索安排
  幕
```

- "前期准备"组：仪表盘/结构/分析（原有 3 个）
- "剧本解析"组：7 个分析阶段独立栏目（原"幕后真相"拆分为 6 个 + 幕）
- 删除"待确认"入口（确认弹窗已覆盖此功能）

**F1.2 模型连接移到右上角**
- 删除侧边栏"系统/模型连接"入口
- 顶部工具栏（topbar）右侧新增⚙️图标按钮
- 点击图标 → 打开设置面板（模态弹窗或侧滑面板）
- 设置面板内容复用现有 `SettingsView`

### F2. 7 阶段独立栏目 + 书页风格

**F2.1 7 个独立栏目**

每个分析阶段一个独立页面（不再是 OverviewView 统一展示）：

| 栏目 | 数据来源 | 展示内容 |
|---|---|---|
| 故事背景 | `analysis.overview` | oneLine/cause/history/currentState/plans/endings/conflicts |
| 时间地点 | `analysis.timePlace` | timeline 概要 + places 列表 |
| 核心人物 | `analysis.people` | 人物卡片网格（importance 分层） |
| 人物经历与动机 | `analysis.characterArcs` | 每人经历+动机 |
| 开篇钩子 | `analysis.openingHook` | 纯文本 |
| 关键线索安排 | `analysis.clues` | 线索卡片网格（importance 分层） |
| 幕 | `analysis.acts` | 树状图 + 幕详情（保持现状） |

**F2.2 书页风格应用范围**
- 前 6 阶段（故事背景~关键线索安排）：书页风格背景
- 幕详情：书页风格背景
- 幕树状图：保持现状（不用书页）
- **不影响**：左侧菜单栏、顶部工具栏、项目仪表盘、文档结构、分析流程页

**F2.3 书页风格元素**
- 背景：用户提供的 AI 书页素材（泛黄纸张 + 红色装饰边框 + 纸张纹理）
- 字体：古奥衬线字体（宋体/思源宋体）
- 内容区域：流式排版（像 Markdown 文档），不刻意分左右页
- 素材路径：`public/book-page-bg.png`

**F2.4 简单翻页**
- 每个阶段页面顶部：`← 上一页    [阶段名]    下一页 →`
- 上一页/下一页按钮在 7 个阶段间切换
- 支持键盘左右箭头键翻页
- 第一页无"上一页"，最后一页（幕）无"下一页"或跳转到幕树状图

### F3. 内容篇幅调整

**F3.1 prompt 加字数要求**

| 阶段 | 字数要求 |
|---|---|
| 故事背景 | oneLine + cause + history + currentState 总计 300-500 字 |
| 人物经历与动机 | 每人 experience 150-200 字 |

其他阶段保持现有篇幅。

### F4. 章节总结 UI 删除

- 删除 `app/components/chapter-summary-view.tsx` 文件
- 删除 `StructureView` 中的"查看总结"按钮和展开逻辑
- 删除 `buildChapterSummaries` 函数和 acts 阶段后的调用
- 保留 `ChapterSummary` 类型定义（未来预留）
- 保留 `ProjectAnalysis.chapterSummaries` 字段（默认空数组）

### F5. 人物卡点击分层显示

**F5.1 幕详情中的人物卡点击**
- 当前：点击人物卡 → 显示简单文字通知（哪些幕包含此人）
- v0.6：点击人物卡 → 弹出人物详情面板，显示：
  - 人物基本信息（姓名/身份/动机）
  - 该人物在所有幕中的出现记录（幕标题列表，可点击跳转）
  - 该人物关联的线索（线索名列表）
  - 肖像上传入口

### F6. 其他待办

- v0.5.1 推迟的章节总结 UI 删除（合并到 F4）
- v0.5 遗留的人物卡分层（合并到 F5）

## 二、非功能需求

| ID | 需求 | 说明 |
|---|---|---|
| N1 | 书页素材本地化 | `public/book-page-bg.png`，不加载外部图片 |
| N2 | 不影响现有功能 | 菜单栏/顶部栏/仪表盘/结构/分析页保持现状 |
| N3 | 性能 | 书页背景图压缩，不影响渲染速度 |
| N4 | 响应式 | 书页内容区域在不同屏幕尺寸下可读 |

## 三、边界（明确不做）

| 事项 | 说明 | 去向 |
|---|---|---|
| 真实翻页效果（3D 翻转） | 鼠标按住拖动翻页 | v0.7 |
| 双页铺平 | 单页展示 | 不做 |
| 全 App 书卷风格 | 只前 6 阶段+幕详情 | 不做 |
| 章节总结重新实现 | 只删除 UI，不重做 | 后续版本 |

## 四、数据模型变更

无新增类型，仅删除章节总结生成逻辑：

| 实体 | 变更 | 说明 |
|---|---|---|
| `ProjectAnalysis.chapterSummaries` | 保留字段，不再生成 | 默认空数组 |
| `ChapterSummary` 类型 | 保留 | 未来预留 |
| `buildChapterSummaries` 函数 | 删除 | 不再调用 |
