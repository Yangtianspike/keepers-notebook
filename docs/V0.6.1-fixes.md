# 守秘人图谱 v0.6.1 修复任务单

## PATCH-UI-01: 全局改造为书本式阅读器 + 幕默认文本视图

> 触发来源：用户反馈当前阶段视图使用 `100vh` 强制占满一屏并拉伸书卷背景，不像 PDF/书本；希望整个 APP 像固定尺寸的书本，左侧菜单当目录，内容在书页上左右翻页；幕默认进入文本内容，右上角放置幕树切换按钮。

### 目标效果

参考 `https://www.jmzs666.cn/#floor5` 的书籍/翻页氛围，并结合用户验收截图对 `https://www.jmzs666.cn/#floor4` 的明确期望，保持守秘人图谱的备本工具属性：

1. **整本书固定尺寸**：不再使用 `min-height: 100vh` 把书页拉长，书页高度固定，超出一页的内容通过翻页切换，而不是向下滚动。
2. **左侧菜单 = 目录/书签**：菜单项像 PDF 目录一样，点击跳转到对应章节/分析阶段。
3. **内容在书页内呈现**：每个阶段（故事背景、核心人物、幕等）都放在一页书里，使用左右翻页按钮切换上一阶段/下一阶段。
4. **幕默认显示文本内容**：从"关键线索安排"按"下一页"进入"幕"时，直接显示幕的文本阅读视图，而不是树状图。
5. **幕树入口放在右上角**：在幕文本视图的右上角放一个类似 ⚙ 设置按钮的"幕树"按钮，点击后切换到树状图；树状图里再提供返回文本视图的入口。
6. **移除/替换书卷背景**：删除把背景图纵向拉伸的做法，书页使用纸质纹理或纯色即可。
7. **左侧菜单颜色保持原方案**：本次 PATCH 不改左侧菜单原有配色，只改布局和书页区域样式。验收反馈左侧 UI 颜色不应变更。

#### F. 书页舞台与书页卡片（来自 viewer.css，**核心！**）

```css
/* 「舞台」：书页所在的可视区域，占满除顶栏外的整屏 */
.stage {
    position: absolute;
    inset: 44px 0 0;          /* 顶部留出 44px 给工具条 */
    display: flex;
    align-items: center;
    justify-content: center;
    overflow: hidden;         /* 舞台本身不滚动 */
    padding: 18px 22px 16px;
}

/* 可缩放层（我们可省略缩放，但保留容器层级） */
.book-zoom {
    display: flex;
    align-items: center;
    justify-content: center;
    transition: transform 0.18s ease;
    transform-origin: center center;
    will-change: transform;
}

/* 翻书容器：水平居中、带厚重投影 */
.flipbook {
    position: relative;
    filter: drop-shadow(0 26px 46px rgba(0, 0, 0, 0.42));
}

/* 单页书页：米色纸张色 */
.flipbook .book-page,
.flipbook .blank-page {
    overflow: hidden;
    background: var(--paper);
}

.flipbook .book-page {
    position: relative;
}

/* 书页加载占位渐变（我们可保留作为加载效果） */
.flipbook .book-page::before {
    content: "";
    position: absolute;
    inset: 0;
    background:
        linear-gradient(90deg, rgba(0, 0, 0, 0.08), transparent 18%,
                        transparent 82%, rgba(0, 0, 0, 0.1)),
        #efe5d5;
    opacity: 1;
    transition: opacity 0.18s ease;
}

.flipbook .book-page.is-loaded::before {
    opacity: 0;
}

/* 单页内容：图片占满 */
.flipbook .book-page img {
    position: relative;
    z-index: 1;
    display: block;
    width: 100%;
    height: 100%;
    object-fit: cover;
    user-select: none;
    -webkit-user-drag: none;
}

/* 偶数页（左页）内侧阴影，模拟书脊 */
.flipbook .even {
    box-shadow: inset -18px 0 26px rgba(0, 0, 0, 0.16);
}

/* 奇数页（右页）内侧阴影 */
.flipbook .odd {
    box-shadow: inset 18px 0 26px rgba(0, 0, 0, 0.18);
}
```

要点（**开发 agent 必须照此实现**）：

1. **三层结构**：
   - `.stage`（舞台）= 占满除顶栏外的整屏，**自身 `overflow: hidden` 不滚动**，用 flex 居中其内容。
   - `.book-zoom`（缩放层）= 可选，保留层级即可。
   - `.flipbook`（书页容器）= 水平居中，带 `drop-shadow` 投影。
   - `.book-page`（单页）= 米色纸张色，内部内容（在我们的项目里是阶段文字/卡片）`overflow: auto` 滚动。
2. **`.stage` 用 `position: absolute; inset: 44px 0 0`** 而不是 `min-height: 100vh`——这是关键，它让舞台固定大小，不再被内容撑高。
3. **书脊阴影**：左页 `.even` 用 `inset -18px 0 26px` 模拟左侧书脊阴影，右页 `.odd` 用 `inset 18px 0 26px` 模拟右侧书脊阴影。**即使我们暂时只做单页，也要保留这套阴影**，让书页看起来像真实书本的一页。
4. **书页背景色用 `var(--paper)` = `#e7ddcc`**（米色），不是纯白。
5. **投影**：`filter: drop-shadow(0 26px 46px rgba(0,0,0,0.42))` 让书页有漂浮在桌面之上的厚重感。
6. **加载占位**：`.book-page::before` 的渐变在内容加载完成后通过 `.is-loaded` 透明度归零。我们可在 `StageView` 渲染阶段数据前显示该占位。
