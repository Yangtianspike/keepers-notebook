#### 2. 书页卡片样式（`app/globals.css` + `app/components/stage-view.tsx`）

**改什么**：

把现有的 `.stage-view`（用 `min-height: calc(100vh - ...)` 拉伸）改成参考网站的固定尺寸卡片结构。只取参考网站的以下层：

| 层 | 参考网站 class | 作用 | 本次是否照搬 |
|---|---|---|---|
| ① | `html, body { overflow: hidden }` | 禁止整页滚动 | 照搬（在书页容器层级实现等价效果） |
| ② | `.viewer-shell` 深色桌面背景 | 桌面氛围 | **不照搬，保持现有桌面背景** |
| ③ | `.stage { position: absolute; inset; overflow: hidden; flex居中 }` | 固定大小舞台 | 照搬 |
| ④ | `.flipbook { drop-shadow(...) }` | 书页漂浮阴影 | 照搬 |
| ⑤ | `.book-page { background: var(--paper) }` | 米色纸张色 | **不照搬，继续用 `book-page-bg.png`** |
| ⑥ | `.book-page::before` 渐变 | 纸张边缘厚度感 | 照搬 |
| ⑦ | `.flipbook .even / .odd` inset box-shadow | 书脊阴影 | 照搬 |
| ⑧ | turn.js 翻页动画 | 翻页动效 | **本次不做，明天再说** |

**具体要求**：

- `.stage-view` 或新增 `.book-page` 容器：
  - 用 `position: absolute` + `inset` 或等价方式固定大小，**不再用 `min-height: calc(100vh - ...)`**
  - `overflow: hidden`，内容超出时内部滚动
  - flex 居中
  - 保留 `book-page-bg.png` 作为书页背景图
- 书页容器加 `filter: drop-shadow(0 26px 46px rgba(0, 0, 0, 0.42))` 漂浮阴影
- 书页 `::before` 加左右边缘渐变 `linear-gradient(90deg, rgba(0,0,0,0.08), transparent 18%, transparent 82%, rgba(0,0,0,0.1))`
- 书页保留一侧 `inset box-shadow` 模拟书脊（单页时取 `.odd` 的 `inset 18px 0 26px rgba(0,0,0,0.18)`）
- `StageView` 组件结构调整：顶部阶段编号 + 标题 → 正文 children → 底部翻页按钮，保持现有翻页交互不变
- 键盘左右箭头翻页保持不变

#### 3. 幕视图（`app/page.tsx` + `app/components/act-text-view.tsx`）
