# 守秘人图谱 v0.6.3 修复任务单

## PATCH-UI-03: 书页去滚轮 + 内容自动分页

> 触发来源：v0.6.2 验收反馈——书页内部出现了滚动条，不符合"像 PDF 一样一页写满翻下一页"的预期；且当前仍是单页形式，不像参考网站的双页并排。

### 问题定位

**文件**：`app/globals.css`

**问题代码**（约 3728-3737 行）：

```css
.stage-view-content {
  width: 100%;
  max-width: 820px;
  min-height: 0;
  overflow-y: auto;          /* ← 滚轮来源，必须去掉 */
  flex: 1 1 auto;
  margin: 0 auto;
  padding: clamp(16px, 2vw, 28px);
  scrollbar-color: rgba(123, 82, 50, 0.46) transparent;
}
```

### 核心需求

用户要的是**像 PDF 一样的阅读体验**：
- 书页固定大小，不滚动
- 内容写满一页后，自动流到下一页
- 通过翻页按钮切换页面
- **不是**在单个书页内部滚动

### 具体修改清单

#### 1. 去掉书页内部滚动条

**文件**：`app/globals.css`

- `.stage-view-content` 的 `overflow-y: auto` 改为 `overflow: hidden`
- 删除 `scrollbar-color` 属性
- 确保 `.stage-view`、`.book-page-content`、`.stage-view-content` 任何一层都**不出现** `overflow-y: auto` 或 `overflow: scroll`

#### 2. 实现内容自动分页

**文件**：`app/components/stage-view.tsx`

**原理**：书页内容是动态 HTML 文本，不是预先分好页的图片。需要用 JS 在渲染时计算内容高度，把超出单页的内容自动切到下一页。

**实现方案**：

1. `StageView` 内部维护一个 `currentPage` 状态和 `totalPages` 状态。
2. 书页内容区（`.stage-view-content`）固定高度，`overflow: hidden`。
3. 渲染时用一个**隐藏的测量层**（`position: absolute; visibility: hidden;`）放入全部内容，遍历子节点累加高度，当累计高度超过书页内容区可用高度时，记录分页断点。
4. 只渲染当前页对应的节点区间。
5. 翻页按钮切换 `currentPage`，键盘左右箭头也切换。
6. 底部页码显示 `currentPage / totalPages`。

**关键约束**：
- 分页计算在 `useLayoutEffect` 中执行，确保 DOM 测量准确。
- 窗口 resize 时重新分页（`useEffect` + `resize` 事件）。
- 内容变化时（阶段切换、数据更新）重新分页。
- 分页断点应落在块级元素边界（段落、标题、卡片），不要在文字中间断开。

**参考伪代码**：

```tsx
const contentRef = useRef<HTMLDivElement>(null);
const measureRef = useRef<HTMLDivElement>(null);
const [currentPage, setCurrentPage] = useState(0);
const [pageBreaks, setPageBreaks] = useState<number[]>([]);

useLayoutEffect(() => {
  if (!measureRef.current || !contentRef.current) return;
  const containerHeight = contentRef.current.clientHeight;
  const children = Array.from(measureRef.current.children);
  const breaks: number[] = [0];
  let accumulated = 0;
  children.forEach((child, index) => {
    const childHeight = (child as HTMLElement).offsetHeight;
    if (accumulated + childHeight > containerHeight && index > 0) {
      breaks.push(index);
      accumulated = childHeight;
    } else {
      accumulated += childHeight;
    }
  });
  setPageBreaks(breaks);
  setCurrentPage(0);
}, [children, containerHeight]);

const totalPages = pageBreaks.length;
const startIdx = pageBreaks[currentPage] ?? 0;
const endIdx = pageBreaks[currentPage + 1] ?? children.length;
const visibleChildren = children.slice(startIdx, endIdx);
```

#### 3. 双页并排布局

**文件**：`app/components/stage-view.tsx` + `app/globals.css`

参考网站是双页并排（左页 even + 右页 odd），中间有书脊阴影。本次实现双页并排布局：

- 书页容器 `.flipbook` 内部用 `display: flex` 横向排列两个 `.book-page`：
  - 左页 `.book-page.even`：`box-shadow: inset -18px 0 26px rgba(0, 0, 0, 0.16);`（右侧书脊阴影）
  - 右页 `.book-page.odd`：`box-shadow: inset 18px 0 26px rgba(0, 0, 0, 0.18);`（左侧书脊阴影）
- 两页之间不留间距，书脊阴影自然衔接
- 内容分页后，**奇数页内容放左页，偶数页内容放右页**（即一次翻页 = 左右两页同时切换）
- 移动端（`@media (max-width: 760px)`）可回退为单页显示，只显示右页

**分页与双页的关系**：
- 分页逻辑计算出的每一页，对应双页并排时的一对（左+右）
- 即：`pageBreaks` 数组按"每页能容纳的内容"计算，渲染时 `currentPage` 对应左页，`currentPage + 1` 对应右页
- 翻页时 `currentPage` 步进 2（一次翻一对）
- 页码显示 `Math.ceil(currentPage / 2) + 1 / Math.ceil(totalPages / 2)`

#### 5. 翻页交互

- 底部"上一页""下一页"按钮切换页对（一次翻左右两页）

- 当翻到最后一对页时，"下一页"按钮触发阶段切换（跳到下一个阶段的第一对页）
- 当在第一对页时，"上一页"按钮触发阶段切换（跳到上一个阶段的最后一对页）
- 页码显示 `当前页对 / 总页对数`
