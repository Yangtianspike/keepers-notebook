- [ ] 阶段编号 14px 灰色居中（验证：DevTools 检查 `.stage-page-heading small` 的 `font-size` 为 `14px`，`color` 为 `#8b7355`）

- [ ] 阶段标题 28px 加粗居中（验证：DevTools 检查 `.stage-page-heading strong` 的 `font-size` 为 `28px`）

- [ ] h2 小节标题 20px 加粗左对齐（验证：DevTools 检查 `.stage-document h2` 或 `.book-page-body h2` 的 `font-size` 为 `20px`）

- [ ] h3 三级标题 17px 加粗（验证：DevTools 检查 h3 的 `font-size` 为 `17px`）

- [ ] 正文 15px 行距 1.8 首行缩进 2em（验证：DevTools 检查 `.stage-document p` 或 `.book-page-body p` 的 `font-size: 15px; line-height: 1.8; text-indent: 2em`）

- [ ] 删除旧字号定义（验证：全局搜索 `clamp(28px, 4vw, 46px)` 和 `.stage-prose > p { font-size: 18px` 均无匹配）

## 翻页动画

- [ ] 翻页时有 3D 卷曲动画（验证：打开"故事背景"页面，点击"下一页"，观察书页有 3D 卷曲翻页效果，而非瞬间切换）

- [ ] 翻页动画时长约 800ms（验证：用 DevTools Performance 面板录制翻页操作，动画持续时间约 800ms）

- [ ] 底部翻页按钮触发 turn.js 翻页（验证：点击"上一页"/"下一页"按钮，书页有动画翻页）

- [ ] 键盘左右箭头触发翻页（验证：按 ArrowRight / ArrowLeft，书页有动画翻页）

- [ ] 页码显示跟随当前页（验证：翻页后底部页码 `当前页 / 总页数` 更新正确）

- [ ] 翻到最后一页 next 触发阶段切换（验证：在"故事背景"最后一页按"下一页"，跳转到"时间地点"第一页）

- [ ] 在第一页 previous 触发阶段切换（验证：在"时间地点"第一页按"上一页"，跳转到"故事背景"最后一页）
