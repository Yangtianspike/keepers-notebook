# 守秘人图谱 v0.7 修复任务单

## PATCH-UI-04: 书页尺寸恢复 + turn.js 翻页动画 + 排版规范统一

> 触发来源：v0.6.3 验收后，书页双页并排已实现但尺寸太小；字号不统一（h1 用 4vw 响应式导致大屏下超大，h2/h3/p 无定义）；翻页动画尚未实现。

### 问题定位

#### 1. 书页尺寸太小

**文件**：`app/globals.css`

**问题代码**：

```css
/* 阶段页 */
.stage-view {
  width: min(1100px, 100%);
  height: clamp(520px, calc(100vh - 132px), 760px);  /* ← 上限 760px 太小 */
}

/* 幕页 */
.book-page-content {
  width: min(1100px, 100%);
  height: clamp(560px, calc(100vh - 118px), 800px);  /* ← 上限 800px 太小 */
}
```

**原因**：`clamp` 的上限（760px / 800px）卡死了书页高度。在 1080p 屏幕上可用高度约 948px，但被限制在 760px，浪费了 188px。参考网站没有上限，书页高度 = `100vh - 78px` 动态填满。

#### 2. 字号不统一

**文件**：`app/globals.css`

**问题代码**：

```css
.stage-document h1 {
  font-size: clamp(28px, 4vw, 46px);  /* ← 4vw 响应式，大屏下 46px 超大 */
}

.stage-document h2 { /* 无 font-size，继承全局，可能很大 */ }
.stage-document h3 { /* 无 font-size */ }
.stage-document p  { /* 无 font-size，继承默认 */ }

.stage-prose > p {
  font-size: 18px;  /* 只有这个有定义，其他段落没有 */
  line-height: 2;
}
```

**原因**：标题用了 `4vw` 响应式字号，宽屏下过大；h2/h3/p 无统一定义，各自继承导致大小不一。

#### 3. 翻页动画未实现

v0.6.3 用 CSS column 分页 + 状态切换，无翻页动效。

#### 3. turn.js 翻页动画集成

**依赖**：
- 安装 `turn.js 4`（`npm install turn.js` 或下载 `turn.min.js` 放入 `public/` 目录）
- 安装 `jquery`（`npm install jquery`）——turn.js 依赖 jQuery

**文件**：
- `app/components/stage-view.tsx`（主改造）
- `app/components/act-text-view.tsx`（同步）
- `app/globals.css`（补充 turn.js 需要的样式）

**实现方案**：

1. **DOM 结构调整**（对齐参考网站）：

```html
<div class="stage">                    <!-- 舞台，占满除顶栏外整屏 -->
  <div class="book-zoom">              <!-- 缩放层（保留层级） -->
    <div class="flipbook" ref={flipbookRef}>  <!-- turn.js 挂载点 -->
      <div class="book-page" id="page-1">...</div>
      <div class="book-page" id="page-2">...</div>
      ...
    </div>
  </div>
</div>
```

2. **turn.js 初始化**（在 `useEffect` 中）：

```tsx
useEffect(() => {
  if (!flipbookRef.current) return;
  const $flipbook = $(flipbookRef.current);
  $flipbook.turn({
    width: 1100,           // 双页总宽度
    height: calcHeight(),  // 动态高度 = 100vh - 132px
    autoCenter: false,
    gradients: true,      // 翻页时的光影渐变
    elevation: 50,        // 翻页时书页抬起高度
    acceleration: true,   // 硬件加速
    duration: 800,         // 翻页动画时长 ms
    page: 1,              // 初始页
  });

  return () => {
    $flipbook.turn('destroy').remove();
  };
}, []);
```

3. **翻页交互**：

- 底部"上一页""下一页"按钮调用 `$flipbook.turn('previous')` / `$flipbook.turn('next')`
- 键盘 `ArrowLeft` / `ArrowRight` 同样调用
- `page` 事件监听当前页码，更新底部页码显示
- 当翻到最后一页时，`next` 触发阶段切换（跳到下一阶段第一页）
- 当在第一页时，`previous` 触发阶段切换（跳到上一阶段最后一页）

4. **分页逻辑调整**：

- turn.js 要求**所有页提前渲染好 DOM**（每页一个 `.book-page`），不能再像 v0.6.3 那样用 CSS column 动态分页
- 改为：在 `useLayoutEffect` 中把内容按高度切分成多个 `.book-page` 节点，全部渲染到 `.flipbook` 内，由 turn.js 接管翻页
- 双页并排由 turn.js 自动处理（奇数页在左、偶数页在右）

5. **CSS 补充**：

```css
/* turn.js 需要的样式 */
.flipbook {
  position: relative;
  filter: drop-shadow(0 26px 46px rgba(0, 0, 0, 0.42));
  overflow: hidden;
}

.flipbook .book-page {
  overflow: hidden;
  background: var(--paper, #e7ddcc);
  background-image: url("/book-page-bg.png");
  background-size: cover;
}

/* turn.js 翻页时的光影效果 */
.flipbook .even {
  box-shadow: inset -18px 0 26px rgba(0, 0, 0, 0.16);
}
.flipbook .odd {
  box-shadow: inset 18px 0 26px rgba(0, 0, 0, 0.18);
}

/* 翻页动画时的渐变 */
.flipbook .page-wrapper {
  perspective: 2000px;
}
```
