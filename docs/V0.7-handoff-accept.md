## 改动文件

- `package.json` / `package-lock.json`：声明 jQuery 与 turn.js 依赖及版本覆盖。
- `public/jquery-3.7.1.min.js` / `public/turn.min.js`：浏览器端脚本，避免运行时依赖外部 CDN。
- `app/components/stage-view.tsx`：新增 `measureAndSlice`、`useTurnBook`，初始化和销毁 turn.js，支持按钮、键盘、边界阶段跳转及移动端单页模式。
- `app/components/act-text-view.tsx`：幕文本接入 `useTurnBook`，翻完当前幕后切换相邻幕，保留幕树、编辑和持久化回调。
- `app/globals.css`：恢复动态书页高度，统一排版，移除 CSS column 分页并添加 turn.js 页面、书脊和透视样式。
- `eslint.config.mjs`：排除 vendored 第三方压缩脚本及本轮临时 npm 缓存。
