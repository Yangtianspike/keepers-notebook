## 核心实现要点

### 1. 书页尺寸恢复

```css
/* 改前 */
.stage-view { height: clamp(520px, calc(100vh - 132px), 760px); }
.book-page-content { height: clamp(560px, calc(100vh - 118px), 800px); }

/* 改后 */
.stage-view { height: calc(100vh - 132px); }
.book-page-content { height: calc(100vh - 118px); }
```

### 2. 排版规范（已确认）

| 元素 | 字号 | 其他 |
|------|------|------|
| 阶段编号 | 14px | 灰色 `#8b7355`，居中 |
| 阶段标题 | 28px | 加粗，居中 |
| 副标题 | 20px | 居中，棕色 `#7b211e` |
| h2 小节 | 20px | 加粗，左对齐 |
| h3 三级 | 17px | 加粗 |
| 正文 | 15px | 行距 1.8，首行缩进 2em |
| 段落间距 | 12px | — |

**删除旧定义**：`clamp(28px, 4vw, 46px)` 和 `.stage-prose > p { font-size: 18px; line-height: 2; }`

### 3. turn.js 集成

**DOM 结构**：
```html
<section class="stage-view flipbook" ref={flipbookRef}>
  {pages.map((page, i) => (
    <div className="book-page" key={i}>{page}</div>
  ))}
</section>
```

**初始化**：
```ts
$(flipbookRef.current).turn({
  width: 1100,
  height: window.innerHeight - 132,
  autoCenter: false,
  gradients: true,
  elevation: 50,
  acceleration: true,
  duration: 800,
  page: 1,
});
```

**翻页**：`turn('previous')` / `turn('next')`
**清理**：组件卸载时 `turn('destroy')`
**内容变化**：`turn('page', 1)` 重置

### 4. 分页逻辑

用 `measureAndSlice` 函数把内容按书页高度切分成多个 `.book-page` 节点：
1. 隐藏测量层渲染全部内容
2. 遍历子节点累加 `offsetHeight`
3. 超过 `pageHeight` 时记录断点（落在块级元素边界）
4. 按断点切分 children 数组

### 5. 阶段边界跳转

- 翻到最后一页时 `next` → 调用 `onNext`（跳到下一阶段）
- 在第一页时 `previous` → 调用 `onPrev`（跳到上一阶段）
