# 守秘人图谱 v0.7 Plan

## 架构概览

v0.7 改造三个层面，不动业务逻辑：

1. **样式层**（`app/globals.css`）：书页尺寸恢复 + 排版规范统一
2. **组件层**（`stage-view.tsx` / `act-text-view.tsx`）：用 turn.js 替换 CSS column 分页
3. **依赖层**（`package.json`）：引入 turn.js 4 + jQuery

### 当前架构（v0.6.3）

```
StageView
  └─ useBookPagination（CSS scrollWidth 分页）
      ├─ viewportRef → .stage-view-content（overflow: hidden）
      └─ flowRef → .paginated-flow（内容流）
  └─ BookPages（装饰性双页背景）
  └─ 翻页按钮 → previousSpread/nextSpread（scrollLeft 切换）
```

### 目标架构（v0.7）

```
StageView
  └─ useTurnBook（turn.js 集成 hook）
      ├─ flipbookRef → .flipbook（turn.js 挂载点）
      └─ pages: Array<ReactNode>（按高度切分后的页面数组）
  └─ 翻页按钮 → turn('previous')/turn('next')
  └─ 阶段切换 → 翻到边界时调用 onPrev/onNext
```

## 核心数据结构

### TurnBookState

```ts
type TurnBookState = {
  currentPage: number;      // turn.js 当前页（1-based）
  totalPages: number;       // 总页数
  pages: ReactNode[];       // 切分后的页面内容数组
};
```

### PageSliceResult

```ts
type PageSliceResult = {
  pages: ReactNode[];       // 切分后的页面数组
  pageBreaks: number[];     // 分页断点（子节点索引）
};
```

## 模块设计

### useTurnBook hook

**职责：** 接管 turn.js 初始化、翻页、分页计算、阶段边界跳转
**对外接口：**
```ts
function useTurnBook(
  content: ReactNode,
  options: {
    width?: number;         // 默认 1100
    height?: number;        // 默认 calc(100vh - 132px)
    onBoundaryPrev?: () => void;
    onBoundaryNext?: () => void;
    contentKey?: unknown;   // 内容变化时重新分页
  }
): {
  flipbookRef: RefObject<HTMLDivElement>;
  currentPage: number;
  totalPages: number;
  previousPage: () => void;
  nextPage: () => void;
  hasPrevious: boolean;
  hasNext: boolean;
}
```
**依赖：** jquery, turn.js

### measureAndSlice 函数

**职责：** 把内容按书页可用高度切分成多个页面
**对外接口：**
```ts
function measureAndSlice(
  content: ReactNode,
  pageHeight: number,
  pageWidth: number,
): PageSliceResult
```
**实现：**
1. 用隐藏测量层（`position: absolute; visibility: hidden;`）渲染全部内容
2. 遍历子节点累加高度
3. 超过 `pageHeight` 时记录断点（断点落在块级元素边界）
4. 按断点切分 children 数组

### StageView 组件（改造）

**职责：** 用 turn.js 渲染书页外壳 + 翻页交互
**对外接口：** 保持不变（`stageIndex, stageName, onPrev, onNext, children`）
**内部：** 用 `useTurnBook` 替换 `useBookPagination`

### ActTextView 组件（改造）

**职责：** 幕内容用 turn.js 渲染
**内部：** 用 `useTurnBook` 替换 `useBookPagination`

## 模块交互

```
page.tsx
  ├─ view=stage-* → StageView(stageIndex, onPrev, onNext, children)
  │                   └─ useTurnBook(children, {onBoundaryPrev: onPrev, onBoundaryNext: onNext})
  │                       └─ measureAndSlice(children, pageHeight, pageWidth)
  │                       └─ $(flipbookRef).turn({...})
  │                       └─ turn('previous'/'next') ← 翻页按钮 / 键盘
  │
  └─ view=acts → ActTextView(acts, onOpenTree, ...)
                   └─ useTurnBook(actContent, {onBoundaryPrev: goPrevAct, onBoundaryNext: goNextAct})
```

## 技术决策

| 决策点 | 选择 | 理由 |
|--------|------|------|
| 翻页库 | turn.js 4 + jQuery | 用户要求与参考网站完全一致 |
| jQuery 集成 | useEffect 中初始化，useRef 持有 DOM | turn.js 是 jQuery 插件，需手动管理生命周期 |
| 分页策略 | JS 高度测量 + 切分 | turn.js 要求所有页提前渲染 DOM，不能用 CSS column |
| 断点策略 | 块级元素边界 | 避免在文字中间断开 |
| 尺寸恢复 | 去掉 clamp 上限 | 参考网站无上限，动态填满 |
| 排版规范 | 固定 px 值 | 避免 vw 响应式导致大屏超大 |
| 组件卸载 | turn('destroy') | 防止内存泄漏 |

### turn.js 集成注意事项

- turn.js 是 jQuery 插件，与 React 集成需在 `useEffect` 中初始化
- 组件卸载时调用 `turn('destroy')` 清理
- 内容变化时调用 `turn('page', newPage)` 而非重新初始化
- turn.js 要求所有 `.book-page` 提前渲染到 DOM
- 翻页动画期间禁用翻页按钮（`turn('isAnimating')` 检测）
