# 守秘人图谱 v0.7 Spec

## 背景

v0.6.3 已实现书页双页并排 + CSS column 分页，但验收发现三个问题：

1. **书页尺寸太小**：`.stage-view` 高度 `clamp(520px, calc(100vh - 132px), 760px)` 上限 760px，在 1080p 屏幕浪费 188px；参考网站无上限，动态填满。
2. **字号不统一**：`.stage-document h1` 用 `clamp(28px, 4vw, 46px)` 响应式，宽屏下 46px 超大；`h2/h3/p` 无统一定义，大小不一。
3. **无翻页动画**：v0.6.3 用 `scrollLeft` 切换，无 3D 卷曲效果。用户要求与参考网站 `https://www.jmzs666.cn/` 一致，使用 turn.js。

## 目标

- 书页动态填满可用空间，视觉上足够大
- 书页内文字排版统一，符合纸质 TRPG 规则书风格
- 翻页时有 turn.js 3D 卷曲动画，和参考网站一致
- 整体 UI 打磨完成，v0.6.x 遗留问题清零

## 功能需求

- F1: 书页尺寸恢复
  - `.stage-view` 高度改为 `calc(100vh - 132px)`，去掉 `clamp` 上限
  - `.book-page-content` 高度改为 `calc(100vh - 118px)`，去掉 `clamp` 上限
  - 宽度保持 `min(1100px, 100%)` 不变
  - 移动端保持 `calc(100vh - 96px)`

- F2: 书页排版规范统一
  - 阶段编号 `02 / 7`：14px，灰色 `#8b7355`，居中
  - 阶段标题：28px，加粗，居中
  - 副标题：20px，居中，棕色 `#7b211e`
  - h2 小节标题：20px，加粗，左对齐，下边框
  - h3 三级标题：17px，加粗
  - 正文段落：15px，行距 1.8，左对齐，首行缩进 2em
  - 段落间距 12px
  - 卡片内正文不缩进
  - 删除 `clamp(28px, 4vw, 46px)` 旧定义
  - 删除 `.stage-prose > p { font-size: 18px; line-height: 2; }` 旧定义

- F3: turn.js 翻页动画集成
  - 引入 turn.js 4 + jQuery 依赖
  - DOM 结构改为多个 `.book-page` 节点，由 turn.js 接管翻页
  - 翻页时有 3D 卷曲动画，时长约 800ms
  - 底部"上一页""下一页"按钮调用 `turn('previous')` / `turn('next')`
  - 键盘 ArrowLeft / ArrowRight 调用 turn.js 翻页
  - 页码显示跟随 turn.js 当前页
  - 翻到最后一页时 `next` 触发阶段切换
  - 在第一页时 `previous` 触发阶段切换
  - 翻页动画启用时禁用内部滚动翻页（CSS column 分页机制移除）

- F4: 幕视图同步
  - `ActTextView` 同样接入 turn.js
  - 幕内容按高度切分成多个 `.book-page`
  - 翻完当前幕所有页后 `next` 切到相邻幕
