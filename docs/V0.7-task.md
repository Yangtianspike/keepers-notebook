## T4: measureAndSlice 分页函数

**文件：** `app/components/stage-view.tsx`
**依赖：** T3
**步骤：**
1. 新增 `measureAndSlice` 函数，接收 `(content: ReactNode, pageHeight: number, pageWidth: number)`
2. 用 `React.createElement` 在隐藏测量层（`position: absolute; visibility: hidden; width: pageWidth;`）渲染全部内容
3. 遍历测量层的子节点，累加 `offsetHeight`
4. 当累加高度超过 `pageHeight` 时，记录当前子节点索引为断点
5. 按断点切分 `children` 数组，返回 `{ pages, pageBreaks }`
6. 断点落在块级元素边界（`div, section, article, p, h2, h3` 等），不在内联元素中间

**验证：** 在 `measureAndSlice` 下方加 `console.log` 输出断点数组和每页子节点数，打开"故事背景"页面，控制台应输出合理分页结果（如 2-3 页）

## T5: useTurnBook hook

**文件：** `app/components/stage-view.tsx`
**依赖：** T1, T4
**步骤：**
1. 新增 `useTurnBook` hook，接收 `(content, options)`
2. 用 `useRef` 持有 `flipbookRef`
3. 在 `useLayoutEffect` 中调用 `measureAndSlice` 切分内容
4. 在 `useEffect` 中初始化 turn.js：
   ```ts
   $(flipbookRef.current).turn({
     width: 1100,
     height: window.innerHeight - 132,
     autoCenter: false,
     gradients: true,
     elevation: 50,
     acceleration: true,
     duration: 800,
     page: 1,
   });
   ```
5. 监听 `turned` 事件更新 `currentPage` 状态
6. 暴露 `previousPage` / `nextPage` / `hasPrevious` / `hasNext` / `currentPage` / `totalPages`
7. `previousPage` 调用 `turn('previous')`，在第一页时调用 `options.onBoundaryPrev`
8. `nextPage` 调用 `turn('next')`，在最后一页时调用 `options.onBoundaryNext`
9. 组件卸载时 `turn('destroy')` 清理
10. `contentKey` 变化时重新分页并调用 `turn('page', 1)` 重置

**验证：** 启动 `npm run dev`，打开"故事背景"页面，控制台应输出 turn.js 初始化日志，无报错
