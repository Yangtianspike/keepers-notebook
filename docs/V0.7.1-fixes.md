# 守秘人图谱 v0.7.1 修复任务单

## PATCH-UI-05：turn.js 分页切片根因修复

> 触发来源：v0.7 验收时发现书页宽度异常窄、"上一页 / 下一页"按钮无效、没有 3D 翻页动画。浏览器控制台确认 jQuery 和 turn.js 均已正常加载。

---

### 问题定位

#### 1. 阶段页只有 1 页，导致宽度窄、翻页失效

`useTurnBook` 通过 `contentBlocks(content)` 读取 `content.props.children` 来决定可分页的"块"（`app/components/stage-view.tsx:54-62`）。`StageView` 把统一注入的阶段标题通过下面这行代码传进子视图：

```tsx
cloneElement(children, undefined, heading, children.props.children)
```

但 **所有阶段子视图都没有渲染 `children`**，并且自带了 `<header>`。以 `BackgroundStageView` 为例：

```tsx
function BackgroundStageView({ project, onOpenSource }: ...) {
  return (
    <article className="stage-document">
      <header>
        <span>故事核心</span>
        <h1>{overview.oneLine}</h1>
      </header>
      <section>...</section>
      ...
    </article>
  );
}
```

结果是：

- `content.props.children` 只有被注入的 `<header className="stage-page-heading">` 一个元素。
- `measureAndSlice` 认为整个阶段内容只有 1 个块，返回 `pages = [content]`（只有一页）。
- turn.js 在 `display: "double"` 下只有一页时，只渲染单页，宽度看起来像窄竖条。
- `totalPages === 1`，`hasNext === false`，"下一页"按钮被禁用，翻页功能消失。
- 子视图真实内容被当成一整页渲染，超出部分被 `.book-page-inner { overflow: hidden }` 截断。

涉及组件（全部在 `app/page.tsx`）：

- `BackgroundStageView`
- `TimePlaceStageView`
- `CharactersStageView`
- `CharacterArcsStageView`
- `OpeningHookStageView`
- `CluesStageView`

#### 2. 幕文本页只有 2 个块，无法按小节分页

`ActTextView` 把全部小节包在 `<div className="book-page-body">` 里（`app/components/act-text-view.tsx:146-326`）：

```tsx
<article className="act-book-document">
  <header className="book-page-header">...</header>
  <div className="book-page-body">
    <section className="act-detail-section">人物</section>
    <section className="act-detail-section">线索</section>
    <section className="act-detail-section">分支结局</section>
    <section className="act-detail-section">阶段性重要事件点</section>
    <section className="act-detail-section">幕描述</section>
  </div>
</article>
```

`contentBlocks` 只能拿到 `[header, bodyDiv]` 两个直接子元素，`bodyDiv` 整体超出即被截断，无法按"人物 / 线索 / 分支结局 / 关键事件 / 幕描述"自然分页。

### 修改清单

#### 1. 阶段子视图统一接收并渲染 `children`

**文件**：`app/page.tsx`

为 6 个阶段子视图组件新增 `children?: ReactNode` prop，把 `children` 渲染在 `<article className="stage-document">` 的最前面，并删除子视图自带的 `<header>`（阶段标题由 `StageView` 统一注入）。

修改模式示例（以 `BackgroundStageView` 为准，其余 5 个同构）：

```tsx
function BackgroundStageView({
  project,
  onOpenSource,
  children,
}: {
  project: Project;
  onOpenSource: (source: SourceRef) => void;
  children?: ReactNode;
}) {
  const overview = project.analysis.overview;
  if (!overview) {
    return (
      <article className="stage-document">
        {children}
        <EmptyState title="尚无故事背景" description="请先完成故事背景分析。" />
      </article>
    );
  }
  return (
    <article className="stage-document">
      {children}
      <section>
        <h2>起因</h2>
        <p>{overview.cause}</p>
      </section>
      <section>
        <h2>开团前的历史</h2>
        <p>{overview.history}</p>
      </section>
      <section>
        <h2>当前状态</h2>
        <p>{overview.currentState}</p>
      </section>
      <section>
        <h2>各方计划</h2>
        <p>{overview.plans}</p>
      </section>
      <section>
        <h2>真相</h2>
        <p>{overview.truth}</p>
      </section>
      <section>
        <h2>导入场景</h2>
        <p>{overview.openingScene}</p>
        {overview.sourceRefs?.map((source) => (
          <button
            key={source.id}
            className="source-link"
            onClick={() => onOpenSource(source)}
          >
            {source.type === "text" ? "📄" : "🖼️"} {source.title}
          </button>
        ))}
      </section>
    </article>
  );
}
```

其余 5 个组件按相同模式修改：

- `TimePlaceStageView`：删除原有 `<header>`，顶部渲染 `{children}`。
- `CharactersStageView`：删除原有 `<header>`，顶部渲染 `{children}`。
- `CharacterArcsStageView`：删除原有 `<header>`，顶部渲染 `{children}`。
- `OpeningHookStageView`：删除原有 `<header>`，顶部渲染 `{children}`。
- `CluesStageView`：删除原有 `<header>`，顶部渲染 `{children}`。

**注意**：

- 不要修改各子视图的业务内容和数据渲染逻辑。
- EmptyState 情况也请用 `<article className="stage-document">` 包裹并渲染 `{children}`，保证阶段标题始终存在。
- 子视图原有 `<header>` 中的 `<span>`（如"故事核心"）和 `<h1>` 由 `StageView` 注入的 `.stage-page-heading` 替代，可直接删除。

#### 2. 修正 `.stage-document > header` 样式冲突

**文件**：`app/globals.css`

注入的标题使用 `.stage-page-heading` 类，现在它作为 `<header>` 子元素位于 `.stage-document` 内部。当前 `.stage-document > header` 选择器会覆盖 `.stage-page-heading` 的 `border-bottom` 和 `padding-bottom`。

修改：

```css
/* 修改前 */
.stage-document > header {
  border-bottom: 2px solid rgba(123, 33, 30, 0.42);
  padding-bottom: 18px;
  text-align: center;
}

/* 修改后 */
.stage-document > header:not(.stage-page-heading) {
  border-bottom: 2px solid rgba(123, 33, 30, 0.42);
  padding-bottom: 18px;
  text-align: center;
}
```

#### 3. 幕文本页面按小节拆分

**文件**：`app/components/act-text-view.tsx`

去掉 `<div className="book-page-body">` 这一层包装，让 `<header className="book-page-header">` 和各 `<section className="act-detail-section">` / `<section className="act-editor">` 成为 `<article className="act-book-document">` 的直接子元素。

即把：

```tsx
<article className="act-book-document">
  <header className="book-page-header">...</header>
  <div className="book-page-body">
    {editing && draft ? (
      <section className="act-editor">...</section>
    ) : (
      <>
        <section className="act-detail-section">...</section>
        <section className="act-detail-section">...</section>
        ...
      </>
    )}
  </div>
</article>
```

改为：

```tsx
<article className="act-book-document">
  <header className="book-page-header">...</header>
  {editing && draft ? (
    <section className="act-editor">...</section>
  ) : (
    <>
      <section className="act-detail-section">...</section>
      <section className="act-detail-section">...</section>
      ...
    </>
  )}
</article>
```

**文件**：`app/globals.css`

由于 `.book-page-body` 不再存在，把依赖它的排版样式扩展到 `.act-book-document`：

```css
/* 修改前 */
.stage-document h2,
.book-page-body h2 { ... }

.stage-document h3,
.book-page-body h3 { ... }

.stage-document p,
.book-page-body p { ... }

.book-page-body,
.act-book-document > .act-editor {
  padding: 0;
}

/* 修改后 */
.stage-document h2,
.act-book-document h2 { ... }

.stage-document h3,
.act-book-document h3 { ... }

.stage-document p,
.act-book-document p { ... }

.act-book-document,
.act-book-document > .act-editor {
  padding: 0;
}
```

### 验收标准

1. 打开"故事背景"阶段，书页宽度恢复正常：桌面端双页并排，每页宽约 500~550px，不再是一条窄竖条。
2. 阶段内容按小节正确分成多页（具体页数视内容高度，但至少大于 1 页）。
3. 点击底部"上一页" / "下一页"按钮，书页出现 3D 卷曲翻页动画，底部页码实时更新。
4. 按键盘 `←` / `→` 可翻页。
5. 翻到阶段最后一页再点"下一页"，仍触发阶段边界跳转（进入下一阶段）。
6. 在"时间地点"第一页点"上一页"，仍触发阶段边界回跳（回到上一阶段最后一页）。
7. 幕文本页面中，"人物 / 线索 / 分支结局 / 关键事件 / 幕描述"等小节能各自独立分页；编辑模式下编辑器占一页或按自然高度分页。
8. 幕边界跳转（幕 1 最后一页翻到幕 2 第一页）仍然正常。
9. 移动端（窗口宽度 ≤ 760px）回退为单页显示，翻页仍然正常。
10. `npm run build`、`npx tsc --noEmit`、`npm run lint`、`npm test` 全部通过。
