# 守秘人图谱 v0.7.2 修复任务单

## PATCH-UI-06：阶段页按小节正确切片（修正 V0.7.1 的遗漏）

> 触发来源：V0.7.1 补丁应用后，阶段页仍然只有 1 页、书页窄、翻页按钮无效。已直接修正并提交。

---

### V0.7.1 为什么没解决问题

V0.7.1 让阶段子视图渲染 `{children}`，但这只改变了子视图的**渲染输出**，并没有改变 `useTurnBook` 读取到的 React 元素树。

`measureAndSlice` 切片依据的是 `contentBlocks(content)`，它读的是 `content.props.children`。`StageView` 原来的 `cloneElement(children, undefined, heading, children.props.children)` 传递的 `children.props.children` 仍然是 `undefined`（阶段子视图作为自闭合标签使用时没有子元素），所以 `content.props.children` 仍然只有被注入的标题一个元素。

因此 `measureAndSlice` 仍然只返回 1 页，问题原封未动。

---

### 根因与正确修复思路

要让 `contentBlocks` 看到真正可分页的块（标题 + 各小节），必须让小节成为传入 `useTurnBook` 的根元素的**直接子元素**。

由于阶段子视图内部硬编码了自己的结构，不能通过 `cloneElement` 只截取其中一部分，所以改为：

1. **阶段子视图不再渲染 `<article>` 和 `<header>`**，改为返回一个 `ReactNode` 片段，里面只包含各小节（或空状态）。
2. **`StageView` 负责把这些片段包进 `<article className="stage-document">`，并在最前面注入统一标题**。
3. **`page.tsx` 不再把子视图作为 JSX 组件渲染，而是作为普通函数调用**，把返回的片段直接传给 `StageView`。

这样 `content.props.children` 就是 `[标题, section, section, ...]`，`measureAndSlice` 可以正确按小节切片。

### 已修改文件

#### 1. `app/components/stage-view.tsx`

- `StageView` 不再使用 `cloneElement` 注入标题。
- 改为直接构造：
  ```tsx
  const content = (
    <article className="stage-document">
      {heading}
      {children}
    </article>
  );
  ```
- 新增 `contentKey` prop 透传给 `useTurnBook`，由调用方传入稳定的 `activeProject` 对象引用，避免每帧重渲染导致无限重测。
- 移除已失效的 `cloneElement` 分支判断。

#### 2. `app/page.tsx`

- 6 个阶段子视图函数签名改为返回 `ReactNode`，去掉 `children?: ReactNode`。
- 每个子视图返回 `<></>` 片段，内部只保留业务小节；删除自带的 `<article>` 和 `<header>`。
- EmptyState 情况直接返回 `<EmptyState />`（由 `StageView` 包在 article 内）。
- `StageView` 调用改为函数调用模式并传入 `contentKey`：
  ```tsx
  <StageView
    stageIndex={0}
    stageName="故事背景"
    contentKey={activeProject}
    ...
  >
    {BackgroundStageView({ project: activeProject, onOpenSource: setSourceRef })}
  </StageView>
  ```

涉及组件：

- `BackgroundStageView`
- `TimePlaceStageView`
- `CharactersStageView`
- `CharacterArcsStageView`
- `OpeningHookStageView`
- `CluesStageView`

#### 3. `app/globals.css`

- 保留 V0.7.1 的 `.stage-document > header:not(.stage-page-heading)` 与 `.act-book-document` 选择器调整。
- 保持样式不变。

### 注意事项

- 阶段子视图现在是普通函数而非 JSX 组件调用，**不要再在 `<StageView>` 里写成 `<BackgroundStageView ... />`**，否则 `contentBlocks` 会把它当成一个整体块，分页仍会失败。
- 标题现在只在**第一页**出现，后续页不再重复注入。如需每页都显示标题，需要再改 `measureAndSlice` 或 StageView 的渲染逻辑。
- 没有修改 `useTurnBook` / `measureAndSlice` 算法本身，只是保证传入的结构符合切片约定。
