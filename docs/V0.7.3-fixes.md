# V0.7.3 补丁：固定尺寸书页、连续页码与翻页修复

## 背景

v0.7 引入 turn.js + jQuery 翻页后，出现以下问题：

1. 书页高度/宽度动态计算，导致测量容器 `.book-measure` 和 turn.js 实际渲染尺寸不一致。
2. 分页切片 `measureAndSlice` 按小节粗切，某些页面内容被 `overflow: hidden` 截断，某些页面几乎空白。
3. turn.js 默认把第 1 页当作右侧封面，初始只显示单页，且翻到第 3 页才有翻页动画。
4. 底部"上一页 / 下一页"按钮红色文字在深色背景上不可见，字号过小。
5. 每个阶段/幕单独统计页码，切换阶段时页码重置，阅读体验不连贯。

本补丁参考缄默之书（jmzs666.cn）的书页布局，采用固定尺寸 + 响应式缩放 + 空白封面页绕过 turn.js 封面模型。

---

## 目标

1. 双页摊开总区域固定为 **1750px × 1200px**，小屏幕等比缩放，最大不超过该尺寸。
2. 单页文本框尺寸 **680px × 1150px**，文本框内边距为 **0**。
3. 总区域上/下外边距 **25px**，左/右外边距 **40px**，中书脊位于总区域中点。
4. 在内容页前插入**空白封面页**，turn.js 从 page 2 开始显示，实现初始 `[内容第1页 | 内容第2页]` 左右展开。
5. 所有阶段/幕内容**连续统页码**，不再每个阶段/幕单独重置。
6. 修复底部翻页按钮样式：白色文字、加边框、字号放大。
7. 修复文字截断与空页问题：统一测量环境与真实渲染环境。

## 尺寸计算

```
总区域宽  = 1750px
总区域高  = 1200px

单页文本框宽 = 680px
单页文本框高 = 1150px（= 1200 - 25 - 25）

左文本框：  x = 40,                width = 680
右文本框：  x = 1750 - 40 - 680 = 1030, width = 680

中间书脊间距 = 1030 - (40 + 680) = 310px
中书脊位置   = 1750 / 2 = 875px

对称检查：
  左文本框中心 = 40 + 340 = 380
  右文本框中心 = 1030 + 340 = 1370
  中书脊 = 380 + (1370 - 380) / 2 = 875 ✓
```

## 文件级修改清单

### 1. `app/components/stage-view.tsx`

#### 1.1 新增固定尺寸常量

```ts
const BOOK_WIDTH = 1750;
const BOOK_HEIGHT = 1200;
const PAGE_WIDTH = 680;
const PAGE_HEIGHT = 1150;
const OUTER_MARGIN_X = 40;
const OUTER_MARGIN_Y = 25;
```

#### 1.2 修改 `useTurnBook` 的 height/width 计算

当前：

```ts
const width = Math.min(1100, element.parentElement?.clientWidth ?? 1100);
const height = Math.max(480, window.innerHeight - heightOffset);
const singleWidth = window.innerWidth <= MOBILE_BREAKPOINT ? pageWidth : pageWidth / 2;
const pageHeight = Math.max(360, window.innerHeight - heightOffset - 132);
```

改为：

```ts
// 根据父容器宽度计算缩放比例
const containerWidth = element.parentElement?.clientWidth ?? BOOK_WIDTH;
const scale = Math.min(1, containerWidth / BOOK_WIDTH);

const width = BOOK_WIDTH * scale;   // 整书宽度
const height = BOOK_HEIGHT * scale; // 整书高度
const singleWidth = PAGE_WIDTH * scale;
const pageHeight = PAGE_HEIGHT * scale;
```

注意：
- `heightOffset` 保留用于计算容器是否需要额外空间，但书页高度不再依赖 `window.innerHeight`。
- `.stage-view` 的 CSS 高度需要同步调整，见下文。

#### 1.3 测量容器 `.book-measure` 尺寸同步

`useLayoutEffect` 中给 `.book-measure` 设置：

```ts
measure.style.width = `${singleWidth}px`;
measure.style.height = `${pageHeight}px`;
```

确保测量时单页宽度和真实书页宽度一致。

#### 1.4 前置空白封面页

在 `measureAndSlice` 返回的 `pages` 数组前插入一个空白页：

```ts
const coverPage = <div className="book-page-inner book-cover-blank" />;
const finalPages = [coverPage, ...result.pages];
setPages(finalPages);
```

空白封面页只占用 turn.js 的封面位置，不显示任何内容。

```ts
  gradients: true,
  elevation: 50,

```

#### 1.6 页码显示扣除空白封面

底部页码显示：

```tsx

  {Math.max(1, currentPage - 1)} / {Math.max(1, totalPages - 1)}
</span>
```

边界判断也要同步：

```ts
const hasPrevious = currentPage > 2;

```

#### 1.7 边界翻页

- 当前在内容第 1 页（turn.js page 2）时，按"上一页"应触发 `onBoundaryPrev`。
- 当前在最后一页时，按"下一页"应触发 `onBoundaryNext`。

#### 1.8 `previousPage` / `nextPage` 调整

```ts
const previousPage = useCallback(() => {
  if (isAnimating) return;
  if (currentPage <= 2) {
    options.onBoundaryPrev?.();
    return;
  }
  turnRef.current?.turn("previous");
}, [currentPage, isAnimating, options]);

const nextPage = useCallback(() => {
  if (isAnimating) return;
  if (currentPage >= totalPages) {
    options.onBoundaryNext?.();
    return;
  }
  turnRef.current?.turn("next");
}, [currentPage, isAnimating, options, totalPages]);
```

#### 1.9 `StageView` contentKey 保持显式

当前已改为显式 `contentKey` prop，保持不变。调用方应传入稳定的内容标识，如 `activeProject.id + view`。

### 2. `app/page.tsx`

#### 2.1 连续统页码：所有阶段共享同一个 turn.js 实例

当前每个 `StageView` 各自调用 `useTurnBook`，页码不连续。

改为：在 `page.tsx` 顶层维护一个全局页数组和当前页码。

简化方案：

1. 保留 `StageView` 组件，但把 `contentKey` 改为基于全局 stage index。
2. 当切换 stage 时，不是销毁重建 turn.js，而是**预先把所有阶段内容切好，合并成一个 pages 数组**。
3. 使用同一个 `flipbookRef`，切换 stage 时调用 `turn("page", targetPage)` 跳转。

更具体的实现建议：

- 在 `page.tsx` 中引入一个新的 `BookReader` 组件（可复用 `useTurnBook`）。
- `BookReader` 接收 `pages: ReactNode[]` 和 `currentPage: number`。
- `page.tsx` 根据当前 `view` 计算目标内容页索引，调用 `book.turn("page", targetPage + 1)` 跳转（+1 是因为有空白封面）。

如果合并改动过大，可以退而求其次：

- 保持每个 `StageView` 独立实例。
- 但页码显示改为"当前阶段页码 + 前面所有阶段累计页数"的样式，例如 `阶段 1/3 · 全局 5/总页数`。

**请开发 agent 根据实际实现复杂度选择其一，优先实现真正的全局连续页码。**

#### 2.2 阶段切换时跳转而非重建

当前 `navigateStage` 只是修改 `view`，导致 `StageView` 卸载/重建。

改为：

```ts
const navigateStage = useCallback((delta: number) => {
  setStageIndex((current) => {
    const next = Math.max(0, Math.min(STAGE_COUNT - 1, current + delta));
    const targetView = STAGE_VIEWS[next];
    setView(targetView);
    // 通知 BookReader 跳转到该阶段对应的全局页码
    setTargetGlobalPage(stageStartPages[next]);
    return next;
  });
}, [stageStartPages]);
```

### 5. 修复分页截断与空页

#### 5.1 统一测量环境

`useLayoutEffect` 中：

```ts
measure.style.width = `${singleWidth}px`;
measure.style.height = `${pageHeight}px`;
measure.style.padding = "0";
measure.style.overflow = "hidden";
```

让测量容器和真实书页容器完全一致。

#### 5.2 精确保留 padding/margin

测量子元素高度时，已经包含 `marginTop` 和 `marginBottom`：

```ts
const heights = nodes.map((node) => {
  const element = node as HTMLElement;
  const styles = window.getComputedStyle(element);
  return element.offsetHeight +
    Number.parseFloat(styles.marginTop || "0") +
    Number.parseFloat(styles.marginBottom || "0");
});
```

当前已有，保持不变。

#### 5.3 处理单个小节超高

如果单个小节高度就超过 `pageHeight`，`measureAndSlice` 会把它整节塞进一页，导致截断。

**修复**：在 `measureAndSlice` 中，对超过 `pageHeight` 的单个 block，按真实高度强行拆分为多页。

简化实现：

```ts
blocks.forEach((block, index) => {
  const blockHeight = measuredHeights[index] ?? pageHeight;
  if (blockHeight <= pageHeight) {
    // 正常累积
    if (index > 0 && accumulatedHeight + blockHeight > pageHeight) {
      pageBreaks.push(index);
      accumulatedHeight = blockHeight;
    } else {
      accumulatedHeight += blockHeight;
    }
  } else {
    // 单节超高，按 pageHeight 拆分
    if (accumulatedHeight > 0) {
      pageBreaks.push(index);
      accumulatedHeight = 0;
    }
    const slices = Math.ceil(blockHeight / pageHeight);
    for (let i = 1; i < slices; i++) {
      pageBreaks.push(index); // 同一 block 连续多页
    }
    accumulatedHeight = blockHeight % pageHeight || pageHeight;
  }
});
```

> ⚠️ 同一 block 跨多页需要更精细的 DOM 克隆。如果实现复杂，可以先用 CSS `column-fill: auto` 或 `overflow: hidden` 配合内容复制作为折中方案。

更稳妥的做法是：对超高的小节，在测量容器中用 `max-height: pageHeight; overflow: hidden` 截取可见部分，生成多页副本，每页偏移 `scrollTop`。

**建议开发 agent 先实现基础拆段，若仍有截断再处理单段超高拆分。**

## 注意事项

1. **不要删除 `.book-measure`**。它是真实测量 DOM 高度的唯一途径。
2. **contentKey 必须稳定**。调用 `StageView` 时传入 `activeProject.id + view` 之类的字符串，不要传对象引用。
3. **空白封面页**不参与页码显示，但要参与 turn.js 内部页码计算。
4. **移动端**需要测试 `display: "single"` 模式下的缩放和翻页。
5. 如果全局连续页码改动过大，可先用"当前阶段页码 + 全局累计"的过渡方案，后续再完全打通。
