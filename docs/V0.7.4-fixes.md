# V0.7.4 补丁：修正文本框尺寸、统一 turn.js 实例与连续翻页

## 背景

V0.7.3 尝试通过固定尺寸 + 空白封面页修复 turn.js 翻页问题，但实际效果仍不符合预期：

1. 书页整体区域未达到 1750×1200，被父容器压缩。
2. `.book-page-inner` 使用百分比宽高和 margin，实际文本区域远小于约定的 680×1150，导致文字换行变多、底部被截断。
3. 空白封面页占据了 turn.js 第 2 页的左侧，导致初始视图不是 `[内容第1页 | 内容第2页]`。
4. 页码和 `pages` 数组索引错位，翻页后出现左侧空白或内容缺失。
5. "上一页"按钮在阶段首页被禁用，因为每个阶段仍是独立的 turn.js 实例。
6. 全局连续页码只是显示层面的偏移，没有真正打通翻页状态。

本补丁从根本结构上修正：统一成一个 turn.js 实例、真实 680×1150 文本框、移除空白封面、让父容器释放足够宽度。

---

## 目标

1. `.book-page-inner` 真实尺寸为 **680px × 1150px**（或按缩放比例等比缩放），内边距为 0。
2. 移除空白封面页，turn.js 直接管理内容页，实现初始 `[第1页 | 第2页]` 左右展开。
3. 所有阶段/幕内容合并为**一个全局 pages 数组**，使用**单个 turn.js 实例**。
4. 切换阶段时不再是卸载/重建 turn.js，而是调用 `book.turn("page", targetPage)` 跳转。
5. 页码真正连续：切换阶段不重置，"上一页/下一页"在当前阶段内翻页，到边界再切换阶段。
6. 父容器 `.workspace` 释放足够宽度，桌面端尽量接近 1750px。
7. 底部按钮保持白字、边框、放大样式。

---

## 尺寸约定

| 项目 | 数值 | 说明 |
|---|---|---|
| 双页摊开总区域 | 1750px × 1200px | turn.js 容器尺寸 |
| 单页尺寸 | 875px × 1200px | turn.js 在 double 模式下自动分配 |
| 单页文本框 | 680px × 1150px | `.book-page-inner` 目标尺寸 |
| 文本框上/下外边距 | 25px | 文本框到单页上下边缘 |
| 文本框左/右外边距 | 97.5px | 使文本框在单页内水平居中：`(875 - 680) / 2` |
| 中书脊位置 | 875px | 总区域中点 |

> 注：单页总宽 875px 是 `1750 / 2`。文本框 680px 在其中居中，左右各留白 97.5px。

## 文件级修改清单

### 1. `app/globals.css`

#### 1.1 释放 `.workspace` 宽度

当前 `.workspace` 可能受父容器 padding 限制。确保：

```css
.workspace {
  width: 100%;
  min-width: 0;
  padding: 0;
  overflow-x: auto; /* 当视口不足 1750px 时出现横向滚动 */
}
```

> 如果整体布局不允许全宽，至少确保 `.workspace` 没有固定 max-width 限制书页。

#### 1.2 修正 `.book-reader`

```css
.book-reader {
  width: 1750px;
  max-width: 100%;
  margin: 0 auto;
  display: flex;
  flex-direction: column;
  align-items: center;
}
```

> 用固定 `width: 1750px` + `max-width: 100%`，桌面端显示 1750px，小屏幕自动缩放。
> 如果父容器宽度不足，书页会按比例缩小（通过 turn.js 的 `size` 计算）。

#### 1.3 修正 `.stage-view` / `.flipbook`

```css
.stage-view,
.flipbook {
  width: 1750px;
  height: 1200px;
  max-width: 100%;
}
```

> 移除 `aspect-ratio`，直接用固定宽高，由 turn.js 负责缩放。

#### 1.4 修正 `.book-page-inner`

```css
.book-page-inner {
  width: 680px;
  height: 1150px;
  margin: 25px 97.5px;  /* 上下 25，左右居中留白 */
  overflow: hidden;
  padding: 0;
  box-sizing: border-box;
}
```

> 关键变更：不再使用百分比，直接用目标像素值。turn.js 缩放书页时，内部会整体等比缩放。

#### 1.5 移除 `.book-page-inner` 的 even/odd margin

删除或覆盖以下样式：

```css
/* 删除或覆盖 */
.flipbook .even .book-page-inner { ... }
.flipbook .odd .book-page-inner { ... }
```

所有 `.book-page-inner` 统一居中。

#### 1.6 移除/保留空白封面相关样式

删除：

```css

.flipbook .book-cover-page { ... }
.flipbook .book-cover-page::before { ... }
```

#### 1.7 按钮样式保持

V0.7.3 的按钮样式已可接受，保留：

### 2. `app/components/stage-view.tsx`

#### 2.1 简化常量

```ts
const BOOK_WIDTH = 1750;
const BOOK_HEIGHT = 1200;
const PAGE_WIDTH = 680;
const PAGE_HEIGHT = 1150;
const MOBILE_BREAKPOINT = 760;
const TURN_DURATION = 800;
```

移除 `heightOffset` 相关逻辑，书页尺寸固定。

#### 2.2 修改 `measureAndSlice`：按真实单页高度切分

保留现有实现，但确保传入的 `pageHeight` 是 `PAGE_HEIGHT`：

```ts
const result = measureAndSlice(content, PAGE_HEIGHT, PAGE_WIDTH, heights);
```

> 当前 `measureAndSlice` 已经处理了单 block 超高拆分，保留即可。

#### 2.3 移除空白封面页

删除：

```ts
const coverPage = (
  <div className="book-page-inner book-cover-blank" key="blank-cover" />
);
setPages([coverPage, ...result.pages]);
```

改为：

```ts
setPages(result.pages);
```

#### 2.4 修改 turn.js 初始化

当前：

```ts
book.turn({
  width,
  height,
  display,
  page: 2,
  // ...
});
```

改为：

```ts
book.turn({
  width,
  height,
  autoCenter: false,
  gradients: true,
  elevation: 50,
  acceleration: true,
  duration: TURN_DURATION,
  display,
  page: 1,  // 关键：不再用空白封面，从第1页开始
});
```

> 在 turn.js 的 double 模式下，`page: 1` 会显示 `[空白左页 | 第1页]`。这是 turn.js 封面模型，无法避免。
> 要初始显示 `[第1页 | 第2页]`，需要配合"虚拟首页"方案，见 2.5。

#### 2.5 （关键）实现 `[第1页 | 第2页]` 初始展开

turn.js 默认会把第 1 页放在右侧。要在初始就看到两页内容，有两种方式：

**方式 A：前置一页不可见的引导页（推荐）**

在 `pages` 数组最前面插入一页**和正常内容页尺寸相同但内容为空**的页（不是 `.book-cover-blank` 那种完全透明的，而是一个真实的书页 div，只是内容为空）。

```ts
const dummyFirstPage = (
  <div className="book-page-inner" key="dummy-first">
    <div className="stage-page-heading" style={{ visibility: "hidden" }}>
      <small>00 / 00</small>
      <strong> </strong>
    </div>
  </div>
);
const finalPages = [dummyFirstPage, ...result.pages];
```

然后初始化 `page: 2`：

```ts
book.turn({
  // ...
  page: 2,
});
```

这样 turn.js 第 2 页显示 `[dummyFirstPage | contentPage1]`，即左页有一个占位的空白书页，右页是内容第 1 页。

但这仍然不是用户要的 `[content1 | content2]`。

**方式 B：让内容从第 2 页开始，turn.js page 1 显示 [content1 | content2]**

这是 turn.js 的另一种行为：在 double 模式下，如果初始化 `page: 1`，它可能显示 `[pages[0] | pages[1]]`。

需要开发 agent 实际测试确认 turn.js 4.x 的 `page: 1` 在 double 模式下到底是：
- `[pages[0]]` 右侧单页，还是
- `[pages[0] | pages[1]]` 左右展开。

**如果 `page: 1` 就是左右展开**，那问题最简单：移除空白封面，`page: 1`，直接 `[content1 | content2]`。

**如果 `page: 1` 是右侧单页**，则需要：
- 让 pages[0] 和 pages[1] 分别对应左页和右页的初始内容；
- 或者接受第一屏右侧单页，第二屏开始展开。

> **请开发 agent 优先测试 `page: 1` 的实际行为。**
> 若 `page: 1` 可直接展开为 `[pages[0] | pages[1]]`，则无需任何封面/占位页。
> 若不行，再考虑在 pages[0] 放左侧占位内容（如阶段标题装饰页），pages[1] 放右侧内容。

#### 2.6 简化页码逻辑

移除 `pageNumberOffset`、`displayCurrentPage`、`displayTotalPages` 等概念。直接显示：

```tsx
<span className="stage-page-number">
  {currentPage} / {totalPages}
</span>
```

因为后续会统一成一个全局实例，页码自然连续。

#### 2.7 `StageView` 改为纯渲染组件（不再调用 useTurnBook）

V0.7.4 要把 turn.js 实例上提到 `page.tsx`。`StageView` 只负责：

1. 渲染测量容器 `.book-measure`。
2. 渲染 `.book-page` 列表（或只渲染内容，由上层 `BookReader` 接管 flipbook）。

建议直接移除 `StageView` 中的 `useTurnBook` 调用，改为接收 `pages`、`flipbookRef`、`measureRef` 等 prop，或者直接删除 `StageView`，由新的 `BookReader` 组件统一渲染。

### 3. `app/page.tsx`

#### 3.1 新增全局内容生成函数

把 6 个阶段子视图的内容合并成一个 ReactNode 数组：

```ts
const stageContents: Record<View, () => ReactNode> = {
  "stage-background": () => BackgroundStageView({ project, onOpenSource: setSourceRef }),
  "stage-timeplace": () => TimePlaceStageView({ project }),
  "stage-characters": () => CharactersStageView({ project }),
  "stage-characterArcs": () => CharacterArcsStageView({ project }),
  "stage-openingHook": () => OpeningHookStageView({ project }),
  "stage-clues": () => CluesStageView({ project }),
};
```

#### 3.2 新增 `BookReader` 组件（或复用改造后的 `StageView`）

`BookReader` 接收：

```ts
type BookReaderProps = {
  contentByStage: Record<View, ReactNode>;
  stageOrder: View[];
  currentStage: View;
  onPrevStage: () => void;
  onNextStage: () => void;
};
```

内部：

1. 用 `useMemo` 或 `useEffect` 把当前及前后阶段的内容合并。
2. 调用 `useTurnBook` 一次性测量并切分所有内容。
3. 维护 `currentPage` 和 `currentStage` 的映射关系。
4. 切换 stage 时，计算目标全局页码，调用 `book.turn("page", targetPage)`。

#### 3.3 计算 stage 起始页码

每个 stage 在全局 pages 数组中的起始位置：

```ts
const stageStartPages = useMemo(() => {
  const result: Record<View, number> = {};
  let offset = 1;
  for (const stage of stageOrder) {
    result[stage] = offset;
    offset += stagePageCounts[stage] ?? 1;
  }
  return result;
}, [stagePageCounts, stageOrder]);
```

切换 stage 时：

```ts
const jumpToStage = (stage: View) => {
  const targetPage = stageStartPages[stage];
  if (targetPage) {
    turnRef.current?.turn("page", targetPage);
  }
};
```

#### 3.4 阶段切换边界处理

"上一页"到当前 stage 首页时，调用 `onPrevStage` 切换到上一阶段，并跳转到上一阶段的最后一页。

"下一页"到当前 stage 末页时，调用 `onNextStage` 切换到下一阶段，并跳转到下一阶段的第一页。

```ts
const handleBoundaryPrev = () => {
  const currentIndex = stageOrder.indexOf(currentStage);
  if (currentIndex > 0) {
    const prevStage = stageOrder[currentIndex - 1];
    const prevStageEndPage = stageStartPages[currentStage] - 1;
    setCurrentStage(prevStage);
    turnRef.current?.turn("page", prevStageEndPage);
  }
};

const handleBoundaryNext = () => {
  const currentIndex = stageOrder.indexOf(currentStage);
  if (currentIndex < stageOrder.length - 1) {
    const nextStage = stageOrder[currentIndex + 1];
    setCurrentStage(nextStage);
    turnRef.current?.turn("page", stageStartPages[nextStage]);
  }
};
```

#### 3.5 移除键盘事件里的 `navigateStage`

当前 `page.tsx` 里有：

```ts
if (event.key === "ArrowLeft") navigateStage(-1);
if (event.key === "ArrowRight") navigateStage(1);
```

这会直接切换 stage，而不是翻页。改为让 `BookReader` 内部处理键盘翻页。

#### 3.6 `StageView` 调用方式

如果保留 `StageView`，改为：

```tsx
<StageView
  stageIndex={0}
  stageName="故事背景"
  contentKey={`${activeProject.id}:stage-background`}
  flipbookRef={globalFlipbookRef}
  measureRef={globalMeasureRef}
  pages={globalPages}
  currentPage={globalCurrentPage}
  totalPages={globalTotalPages}
  previousPage={globalPreviousPage}
  nextPage={globalNextPage}
  hasPrevious={globalHasPrevious}
  hasNext={globalHasNext}
>
  {BackgroundStageView({ project, onOpenSource: setSourceRef })}
</StageView>
```

但更推荐直接删掉 `StageView` 的 flipbook 渲染，统一由 `BookReader` 渲染。

## 推荐实现顺序

1. **先改 CSS**：修正 `.book-page-inner` 为 680×1150，释放 `.workspace` 宽度。
2. **移除空白封面**：让 `pages` 直接等于内容页数组。
3. **测试 turn.js `page: 1` 行为**：确认 double 模式下初始是单页还是双页。
4. **根据测试结果决定初始页方案**。
5. **把 turn.js 实例上提到 `page.tsx`**，所有 stage 共享一个 `BookReader`。
6. **实现阶段边界跳转**：上一页到边界进入上一阶段末页，下一页到边界进入下一阶段首页。
7. **修复键盘事件**：让键盘控制翻页而不是直接切 stage。
8. **运行类型检查、lint、构建、测试**。

## 风险与回退

1. **turn.js `page: 1` 行为不确定**：开发 agent 需要先测试确认。如果 turn.js 4.x 强制第 1 页为右侧单页，则无法直接实现 `[第1页 | 第2页]` 初始展开，需要接受第一屏右侧单页，或改用其他翻页库。
2. **全局实例改动大**：如果合并所有 stage 到一个 `BookReader` 风险高，可先保留每个 stage 独立，但修复文本框尺寸和移除空白封面。
3. **父容器宽度受限**：如果侧边栏和窗口宽度确实放不下 1750px，需要接受等比缩放或横向滚动。
