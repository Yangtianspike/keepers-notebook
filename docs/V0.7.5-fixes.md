# V0.7.5 补丁：分页修复、书页编辑与分析流程 UI 优化

## 背景

V0.7.4 修复了文本框尺寸和连续翻页后，书页仍存在以下问题：

1. 卡片网格（地点档案、人物卡片等）被 `measureAndSlice` 的像素级切片截断，单个卡片被切成两半跨页。
2. 分析流程 UI 左侧导航栏简单，7 个阶段没有清晰的进度指示和加载状态。
3. 无 KP 在书页直接编辑文字的功能。

本补丁合并三个改动，不按正式版本流程，作为 v0.7.x 的累积补丁发布。

---

## 1. 分页修复：卡片不再被截断

### 问题

`measureAndSlice` 以 `<section>` 为最小切分单位。当 section 包含卡片网格（如 `<div className="stage-card-grid">` 里有 10 个 `<article className="stage-inset-card">`），整体 section 高度超过一页。当前算法用 `translateY` 像素级切片，导致：

- 一张卡片上半在第一页底部，下半在第二页顶部。
- 文字排版混乱，跨页时出现不完整卡片。

### 修改方向

把分页最小单位从 `<section>` 细化为 **卡片/段落** 级。卡片网格中的每个 `<article>` 作为独立分页单元，文字段落仍按整体 section 分页但不再被中间截断。

### 实现方式

#### 修改 `app/components/stage-view.tsx` 中的 `contentBlocks`

当前 `contentBlocks` 只取 content 的直接 children：

```ts
function contentBlocks(content: ReactNode) {
  if (isValidElement<{ children?: ReactNode }>(content)) {
    return {
      root: content,
      blocks: Children.toArray(content.props.children),
    };
  }
  return { root: null, blocks: Children.toArray(content) };
}
```

改为递归展开，识别出需要拆分的大容器：

```ts
function extractBlocks(node: ReactNode): ReactNode[] {
  if (!isValidElement(node)) return [node];

  const element = node as ReactElement;
  const type = element.type;

  // 如果是卡片网格，把每个子元素作为独立 block
  if (
    typeof type === "string" &&
    (element.props.className?.includes("stage-card-grid") ||
     element.props.className?.includes("act-card-grid"))
  ) {
    return Children.toArray(element.props.children).flatMap(extractBlocks);
  }

  // 如果是 section 包含多个卡片，展开子元素
  if (typeof type === "string" && type === "section") {
    const children = Children.toArray(element.props.children);
    // 如果 section 内部有 grid 结构，递归展开
    const hasGrid = children.some(
      (child) =>
        isValidElement(child) &&
        typeof child.type === "string" &&
        (child.props.className?.includes("grid") ||
         child.props.className?.includes("stage-card-grid") ||
         child.props.className?.includes("act-card-grid"))
    );
    if (hasGrid) {
      return children.flatMap((child) => {
        if (
          isValidElement(child) &&
          typeof child.type === "string" &&
          (child.props.className?.includes("grid") ||
           child.props.className?.includes("stage-card-grid"))
        ) {
          return Children.toArray(child.props.children).flatMap(extractBlocks);
        }
        return extractBlocks(child);
      });
    }
    return [node];
  }

  // 默认：不再展开，作为独立 block
  return [node];
}

function contentBlocks(content: ReactNode) {
  if (isValidElement<{ children?: ReactNode }>(content)) {
    return {
      root: content,
      blocks: Children.toArray(content.props.children).flatMap(extractBlocks),
    };
  }
  return { root: null, blocks: Children.toArray(content).flatMap(extractBlocks) };
}
```

> **关键**：卡片网格被拆成独立 `<article>`，每个卡片单独参与高度累加。如果某页只能放 3 个完整卡片，第 4 个卡片会推到下一页。section 标题（如 `<h2>地点档案</h2>`）应跟随第一个卡片或单独作为 block，确保标题不孤零零留在上一页底部。

#### 修改 `measureAndSlice` 中的分页策略

当前超高 block 用 `translateY` 切片：

```ts
if (blockHeight > pageHeight) {
  finishPage();
  const sliceCount = Math.ceil(blockHeight / pageHeight);
  for (let sliceIndex = 0; sliceIndex < sliceCount; sliceIndex += 1) {
    const offset = sliceIndex * pageHeight;
    const sliceHeight = Math.min(pageHeight, blockHeight - offset);
    pageBreaks.push(index);
    pageGroups.push([
      <div className="book-block-slice" ...>
        <div style={{ transform: `translateY(-${offset}px)` }}>{block}</div>
      </div>,
    ]);
  }
  currentStart = index + 1;
  return;
}
```

改为：**对于文字段落（`<p>`、`<section>` 无 grid 子元素），仍允许 `translateY` 切片；对于卡片、标题等，不再切片，整 block 推到下一页。**

在 `extractBlocks` 中给每个 block 打标，measureAndSlice 中根据标记决定是否切片：

```ts
function isSplittableBlock(node: ReactNode): boolean {
  if (!isValidElement(node)) return false;
  const element = node as ReactElement;
  if (typeof element.type !== "string") return false;
  // 只有纯文字段落或简单容器才允许切片
  if (element.props.className?.includes("stage-inset-card")) return false;
  if (element.props.className?.includes("act-person-card")) return false;
  if (element.props.className?.includes("act-clue-card")) return false;
  if (element.type === "header") return false;
  return true;
}
```

```ts
blocks.forEach((block, index) => {
  const blockHeight = measuredHeights[index] ?? pageHeight;
  const splittable = isSplittableBlock(block);

  if (!splittable && blockHeight > pageHeight) {
    // 不可切分的 block（卡片、标题）整页放下
    if (currentBlocks.length > 0) {
      finishPage();
    }
    pageBreaks.push(index);
    pageGroups.push([block]);
    currentStart = index + 1;
    return;
  }

  if (splittable && blockHeight > pageHeight) {
    // 可切分的 block（文字段落）按像素切片
    finishPage();
    const sliceCount = Math.ceil(blockHeight / pageHeight);
    for (let sliceIndex = 0; sliceIndex < sliceCount; sliceIndex += 1) {
      const offset = sliceIndex * pageHeight;
      const sliceHeight = Math.min(pageHeight, blockHeight - offset);
      pageBreaks.push(index);
      pageGroups.push([
        <div className="book-block-slice" key={`${index}-${sliceIndex}`} style={{ height: sliceHeight }}>
          <div style={{ transform: `translateY(-${offset}px)` }}>{block}</div>
        </div>,
      ]);
    }
    currentStart = index + 1;
    return;
  }

  if (currentBlocks.length > 0 && accumulatedHeight + blockHeight > pageHeight) {
    finishPage();
    currentStart = index;
  }
  currentBlocks.push(block);
  accumulatedHeight += blockHeight;
});
```

> **注意**：section 标题需要跟随其内容。如果 `<h2>地点档案</h2>` 作为独立 block 出现在页末，但后面的卡片被推到下一页，标题会单独成一页。解决方案：在 `extractBlocks` 中让标题和后续第一个卡片绑定为一个 block，或让标题仍属于其容器 section，只在 section 内部展开子元素。

更简单的方案：不改 `contentBlocks`，改在渲染阶段把卡片网格提前拆分。即 `page.tsx` 中的 `TimePlaceStageView`、`CharactersStageView` 等把卡片渲染成**每个卡片一个 `<section>`**，而不是全部包在一个 `<section>` 里。这样 `measureAndSlice` 自然按 `<section>` 分页，卡片就是独立单元。

**推荐方案 B（改动更小）：**

修改 `page.tsx` 中的子视图，把卡片网格改为每张卡片独立包裹：

```tsx
// 当前
<section>
  <h2>地点档案</h2>
  <div className="stage-card-grid">
    {places.map((place) => <article className="stage-inset-card">...</article>)}
  </div>
</section>

// 改为
<section>
  <h2>地点档案</h2>
</section>
{places.map((place) => (
  <section key={place.id}>
    <article className="stage-inset-card">...</article>
  </section>
))}
```

这样每个卡片是独立的 `<section>`，measureAndSlice 按 section 分页时，卡片不会跨页。

标题 `<h2>` 单独一个 section，可能单独成页。优化：标题和第一个卡片合并在一个 section 中。

#### 2.2 新增 EditableText 组件

在 `app/components/stage-view.tsx` 或新建 `app/components/editable-text.tsx`：

```tsx
"use client";

import { useState, useCallback } from "react";

export function EditableText({
  text,
  onChange,
  className,
}: {
  text: string;
  onChange: (value: string) => void;
  className?: string;
}) {
  const [isEditing, setIsEditing] = useState(false);
  const [draft, setDraft] = useState(text);

  const handleBlur = useCallback(() => {
    setIsEditing(false);
    if (draft !== text) {
      onChange(draft);
    }
  }, [draft, text, onChange]);

  if (isEditing) {
    return (
      <textarea
        className={className}
        value={draft}
        onChange={(e) => setDraft(e.target.value)}
        onBlur={handleBlur}
        onKeyDown={(e) => {
          if (e.key === "Escape") {
            setIsEditing(false);
            setDraft(text);
          }
        }}
        autoFocus
        rows={3}
      />
    );
  }

  return (
    <span className={className} onClick={() => setIsEditing(true)}>
      {text}
    </span>
  );
}
```

## 3. 分析流程 UI 优化

### 修改文件

- `app/page.tsx`（左侧导航栏或新增分析面板）
- `app/globals.css`（分析卡片样式）

### 需求确认

- 7 个分析阶段一行一行排列（纵向列表，每个阶段一行/一格）。
- 所有卡片**同等尺寸**（宽度一致，高度可自适应或固定）。
- 分析按钮（原"分析剧本"）放在卡片区域上方或下方一个全局位置。
- 分析过程中，当前正在分析的阶段显示**转圈加载动画（spinner）**。
- 已完成的阶段显示完成标记，出错的阶段显示错误标记。
- 点击某个阶段卡片，跳转到该阶段阅读界面。

### 实现

#### 3.1 新增分析流程面板组件

在 `app/page.tsx` 中或新建 `app/components/analysis-flow-panel.tsx`：

```tsx
"use client";

import type { AnalysisStage } from "@/lib/types";

const STAGE_ORDER: AnalysisStage[] = [
  "background",
  "timeplace",
  "characters",
  "characterArcs",
  "openingHook",
  "clues",
  "acts",
];

const STAGE_LABELS: Record<AnalysisStage, string> = {
  background: "故事背景",
  timeplace: "时间地点",
  characters: "核心人物",
  characterArcs: "人物经历与动机",
  openingHook: "开篇钩子",
  clues: "关键线索",
  acts: "幕",
};

export function AnalysisFlowPanel({
  stages,
  runningStage,
  onAnalyzeAll,
  onRetryStage,
  onViewStage,
}: {
  stages: Record<AnalysisStage, { status: string; error?: string }>;
  runningStage?: AnalysisStage | null;
  onAnalyzeAll: () => void;
  onRetryStage: (stage: AnalysisStage) => void;
  onViewStage: (stage: AnalysisStage) => void;
}) {
  return (
    <div className="analysis-flow-panel">
      <div className="analysis-flow-header">
        <h2>分析流程</h2>
        <button className="primary-button" onClick={onAnalyzeAll}>
          分析剧本
        </button>
      </div>
      <div className="analysis-stage-list">
        {STAGE_ORDER.map((stage, index) => {
          const status = stages[stage]?.status ?? "idle";
          const isRunning = runningStage === stage;
          return (
            <div
              key={stage}
              className={`analysis-stage-card ${status} ${isRunning ? "running" : ""}`}
              onClick={() => onViewStage(stage)}
            >
              <span className="stage-number">{String(index + 1).padStart(2, "0")}</span>
              <span className="stage-name">{STAGE_LABELS[stage]}</span>
              <span className="stage-status">
                {isRunning ? (
                  <span className="spinner" />
                ) : status === "complete" ? (
                  "✓"
                ) : status === "error" ? (
                  <button
                    className="retry-button"
                    onClick={(e) => {
                      e.stopPropagation();
                      onRetryStage(stage);
                    }}
                  >
                    ⚠ 重试
                  </button>
                ) : (
                  "—"
                )}
              </span>
            </div>
          );
        })}
      </div>
    </div>
  );
}
```

## 注意事项

1. 分页修复推荐**方案 B**（修改子视图渲染结构，让卡片独立成 section），改动最小，无需改 `measureAndSlice` 算法。
2. 编辑功能的数据持久化优先用 `localStorage`（复用 `saveProject`），不引入新存储机制。
3. 分析流程面板只在前期准备阶段（即 analysis 视图）显示，阅读阶段（stage view）不显示。
4. 移动端侧边栏可折叠，分析面板在移动端同样一行一行显示。
