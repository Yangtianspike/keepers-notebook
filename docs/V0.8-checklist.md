# 守秘人图谱 v0.8 验收清单

## 使用说明

开发 agent 按 `docs/V0.8-task.md` 的 T1→T11 串行实现并逐项提交。所有 P0 项通过后，才可生成验收交接。

## 1. 共享 Markdown 管线与安全边界（P0）

- [ ] 阅读渲染与编辑保存共用同一套 Markdown AST/解析/序列化规则。
- [ ] H1–H6、粗体、斜体、下划线、删除线、列表、引用、分隔线可往返保存。
- [ ] GFM 表格和图片可往返保存，不被编辑器静默丢弃。
- [ ] 仅允许受控 HTML 标签、属性、字体值和安全 URL 协议。
- [ ] `script`、事件属性、危险 URL 被删除或拒绝。

## 2. 按钮风格统一（P0）

- [ ] 分析流程的分析剧本、重新分析、分析记录三个按钮同高、同一水平线、同一视觉样式。
- [ ] 剧本解析工具条的上一页、下一页、跳页、编辑书页、幕树使用统一样式。
- [ ] hover、focus、disabled 状态清晰且文字可读。
- [ ] 不改左侧菜单整体风格、桌面背景和 turn.js 翻页引擎。

## 3. 模型输出兼容扩充（P0）

- [ ] 七阶段、现有 action、暂停/确认与整体分析控制流保持不变。
- [ ] characters 阶段可选输出人物摘要、外貌、性格、状态、扮演提示和 CoC 7e 属性。
- [ ] 核心人物与非核心人物均可拥有完整 CoC 7e 属性。
- [ ] 每个属性、技能和攻击独立标记来源值或推断值，混合数据不会被整卡单一标签掩盖。
- [ ] KP override 始终高于模型值。
- [ ] characterArcs 可选输出动机变化和与主线关系。
- [ ] openingHook 保留旧字符串并可选输出五字段详情，模型自动填充且不复述序幕。
- [ ] acts 为每个 `personId` 可选输出行动摘要、来源引用与来源/推断标记。
- [ ] 原文无明确行动时返回“本幕无明确行动”并标记 `none`，不臆造剧情。
- [ ] 旧模型响应和旧项目数据仍可正常读取。

## 4. 核心人物与动机书页（P0）

- [ ] 核心人物阶段展示全部人物，并按核心、重要、次要分组。
- [ ] 核心人物卡显示有值的身份、摘要、外貌、性格、动机、秘密、状态、扮演提示与 CoC 属性。
- [ ] 人物卡只保存实体引用，渲染时动态读取实体与 KP override，不复制易过期快照。
- [ ] “人物经历与动机”改名为“核心人物与动机”，section key 兼容旧数据。
- [ ] 核心人物与动机显示成长弧线、动机变化、与主线关系。
- [ ] 人物名称可打开实体资料窗口。

## 5. 开篇钩子、幕标题与本幕剧情（P0）

- [ ] 开篇钩子包含 GM 开场朗读、玩家初始处境、首个冲突、氛围建议、导入技巧五部分。
- [ ] 已带“序幕/第 N 幕/终幕”前缀的标题不重复添加前缀。
- [ ] 普通幕使用 `act.sequence`；数组第一项不会被自动命名为序幕。
- [ ] “幕描述”改为“本幕剧情”。
- [ ] 每个幕中所有 `personId` 均有行动条目，并带来源/推断信息。
- [ ] 旧项目缺少 `personActions` 时可从 `act.description` 做客户端兼容提取。
- [ ] 人物名称可作为实体链接使用。

## 6. 可视化 Markdown 编辑器（P0）

- [ ] 工具栏支持 H1–H6、斜体、下划线、删除线、表格、图片和受控字体切换。
- [ ] 表格默认可插入并编辑 3×3 内容，书页阅读时不撑破正文区域。
- [ ] 图片 URL 仅允许 http/https/受控 data:image。
- [ ] 本地图片通过原生 canvas 压缩，最长边不超过 1600px，目标单图约 1MB。
- [ ] 项目只持久化 Data URL，不持久化 blob URL；超限时明确提示。
- [ ] 保存、阅读、再次编辑后格式与内容一致。

## 7. 旧项目模板升级（P0）

- [ ] 已有 `sectionMarkdown` 不被启动、分析或升级过程自动覆盖。
- [ ] 提供明确的“应用 v0.8 模板”入口，并在覆盖前二次确认。
- [ ] 用户取消后原 Markdown 保持不变。
- [ ] 升级后实体引用仍动态读取当前实体数据。

## 8. 浮动实体窗口（P0）

- [ ] 人物、线索、地点、事件、自定义实体均可打开羊皮纸风格浮动窗口。
- [ ] 窗口使用 viewport fixed 定位，默认避开触发文字并保持在可见区域内。
- [ ] 窗口可拖动、置顶和单独关闭，拖动不触发 turn.js。
- [ ] 同一实体重复打开时聚焦已有窗口，不创建重复窗口。
- [ ] 离开阅读页、切换项目或进入编辑模式时关闭全部浮动窗口。
- [ ] AI 实体不可删除但可编辑；KP 实体可编辑并按既有规则删除。

## 9. 相关实体与出场信息（P0）

- [ ] 所有实体窗口常驻显示相关实体区域。
- [ ] 关系查询以 `entityRef + project` 为输入，兼容显式关系和同幕共现。
- [ ] 点击相关实体可在窗口历史中打开，并可返回上一实体。
- [ ] 人物出场列表依据所有 acts 的 `personIds/personActions` 汇总，不依赖单一 section 快照。
- [ ] 无关联或无明确行动时显示准确空状态，不编造内容。

## 10. 统一书页与回归（P0）

- [ ] 前六阶段和全部幕继续共用同一 `pages` 数组与同一个 turn.js 实例。
- [ ] 左侧阶段/幕导航、上一页、下一页、跳页、键盘翻页均正常。
- [ ] 离开书页再返回、跨 section 跳转、反复翻页无 React 更新循环或 DOM 层级异常。
- [ ] 页面内容分页不截断文字、表格或图片。

## 11. 最终验证与交付（P0）

- [ ] `npm run lint` 通过。
- [ ] `npm run build` 通过。
- [ ] `npm run test` 通过。
- [ ] 每个 T1→T11 均有独立 commit，未混入无关文件。
- [ ] 已生成 `docs/V0.8-handoff-accept.md`，包含改动文件、逐项证据、已知问题和最终 commit hash。
