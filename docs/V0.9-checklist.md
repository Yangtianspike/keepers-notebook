# V0.9 Checklist：验收清单

## 1. 序幕与分析流程

- [ ] 分析阶段、进度 UI、重新分析目标、目录和独立书页均无“开篇钩子”。
- [ ] 新分析由幕阶段直接生成序幕，序幕内容包含原开篇钩子职责。
- [ ] `acts:prologue` 与其他幕共用一个 pages 数组和 turn.js 实例。
- [ ] 旧 `stage-openingHook` 内容只在序幕显示一次，原数据未被破坏删除。
- [ ] 已保存序幕优先于旧数据；无其他幕时序幕仍可查看。
- [ ] 点击“幕”和“序幕”目录均能跳到正确逻辑页。

## 2. 人物、Boss 与怪物数据

- [ ] `EntityKind` 包含 monster；analysis 支持可选 monsters。
- [ ] 有姓名的人类/类人 Boss 保持 person 且 `isBoss=true`。
- [ ] 非人怪物、神话生物、野兽和无名敌人模板进入 monsters。
- [ ] 人类 Boss 在人物与怪物/Boss 章节引用同一个实体，不产生副本。
- [ ] people/monsters 无重复，怪物名称或别名重复会归并。
- [ ] 怪物 CoC 字段兼容现有 PersonCoCStats，来源标记正确。
- [ ] `Act.monsterIds` 能支持怪物的幕出现信息与关系。

## 3. 怪物与 Boss 章节

- [ ] 章节位于人物和人物经历与动机之间。
- [ ] 无条目时显示“本模组暂无怪物或 Boss”。
- [ ] 所有怪物和 Boss 使用核心人物卡完整规格，而非简化表格。
- [ ] 卡片包含肖像、摘要、身份/类型、详情、KP 信息、CoC、技能和攻击。
- [ ] 怪物/Boss 卡具有图片入口与编辑入口。
- [ ] 卡片按 overview/details/stats 语义分页，不切断属性表、技能项或攻击项。
- [ ] 点击名称打开正确且唯一的实体资料卡。

## 4. 羊皮纸编辑覆盖层

- [ ] 核心人物、Boss、怪物卡均可打开相同风格的羊皮纸覆盖编辑层。
- [ ] 编辑层位于 turn.js 外，打开/关闭不会破坏翻页实例或改变当前页。
- [ ] 名称、别名、图片、公开/KP 字段、CoC、技能和攻击均可编辑。
- [ ] 保存写入 entityOverrides 且来源为 keeper，刷新后仍有效。
- [ ] 取消、关闭和 Esc 不产生任何覆盖变更。
- [ ] 保存后重新分页并恢复原 section 与逻辑页。
- [ ] 书页卡与浮动资料卡显示同一覆盖结果。
- [ ] 重新分析后 KP 覆盖仍保留。

## 5. 书页自适应缩放

- [ ] 工作区按 `100dvh` 和顶部栏实际高度分配剩余空间。
- [ ] 正常桌面视口无需纵向滚动即可看到完整书页。
- [ ] ResizeObserver 能响应窗口和侧栏造成的容器变化。
- [ ] 逻辑分页固定为 680×1150，缩放不改变内容分页。
- [ ] 同单双页模式 resize 不销毁 turn.js；跨断点才安全重建。
- [ ] resize、跨断点、离开返回后保留正确逻辑页。
- [ ] 目录、上一页/下一页、跳页和键盘翻页在缩放后均可用。
- [ ] 视口过小时显示提示且不产生强制尺寸溢出。

## 6. 浮动资料卡自适应缩放

- [ ] 每张资料卡按工作台宽高等比缩放，内容分页不因缩放变化。
- [ ] 标题、正文、图片、按钮和分页控件整体保持比例。
- [ ] resize 与侧栏切换后资料卡仍位于可见范围，关闭按钮可操作。
- [ ] 缩放后拖动、置顶、关闭和翻页正常。
- [ ] 多资料卡同时存在并分别保留页码、位置和层级。
- [ ] 视口太小时出现提示而不是裁掉关键控件。

## 7. 回归与质量

- [ ] 旧项目加载无异常，新字段缺失时正常降级。
- [ ] 前置阶段、序幕、各幕仍共享同一 pages 数组和 turn.js 实例。
- [ ] 时间线、线索图、原始资料、设置和分析流程无回归。
- [ ] 切换分析流程/书页、重复跳章节不出现 React 更新循环或 turn.js DOM 层级异常。
- [ ] `npm run lint` 通过。
- [ ] `npm run build` 通过。
- [ ] `npm run test` 通过。
