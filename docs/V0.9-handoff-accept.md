# 守秘人图谱 v0.9 Handoff → 验收 Agent

## 实现摘要

V0.9 已按修订后的 spec/plan/task 实现：

1. 删除独立“开篇钩子”分析阶段和 UI 入口；幕分析直接生成序幕，旧数据按优先级兼容到 `acts:prologue`。
2. 新增 `Monster`、`analysis.monsters`、`Person.isBoss`、`Act.monsterIds` 和 `monster` 实体类型。
3. 人物分析使用 people/monsters 双集合；人类 Boss 保持 person 引用，非人怪物进入 monsters，并做跨集合及别名去重。
4. 新增“怪物与 Boss”章节；人类 Boss 和怪物都使用核心人物卡的 overview/details/stats 规格、图片区和语义分页。
5. 核心人物、Boss、怪物卡均可打开 turn.js 外的羊皮纸编辑覆盖层，并与浮动资料卡共享 EntityOverrides。
6. 书页改为固定逻辑分页与响应式显示尺寸；ResizeObserver 处理窗口/侧栏变化，同模式只调用 `size`，跨单双页模式才重建并保留逻辑页。
7. 浮动资料卡使用固定逻辑尺寸和等比缩放，resize 后限制在工作区内，保留原有拖动、多窗口和分页行为。

## 验收重点

1. 用含人类 Boss 与非人怪物的中文模组重新执行人物和幕分析，核对分类、原文 CoC 数值与去重。
2. 打开“怪物与 Boss”，确认所有条目均为核心人物卡规格并可编辑。
3. 保存/取消覆盖编辑，刷新及重新分析后核对 KP 覆盖层。
4. 在双页/单页断点反复缩放并切换侧栏，确认逻辑页不回到第一页且无 turn.js DOM 异常。
5. 同时打开多张资料卡后缩放窗口，确认卡片并存、可拖动、可翻页且关闭按钮可见。
