# V0.9 Task：开发任务

按 T1→T9 串行执行；每项验证通过后再进入下一项。

## T1 数据结构与兼容层

- 扩展 `EntityKind`、`Person.isBoss`、`ProjectAnalysis.monsters`、`Act.monsterIds` 和 `Monster`。
- CoC 字段复用现有 `PersonCoCStats`，`entityCoCStats` 支持 person/monster。
- 增加序幕来源优先级解析器，保留旧数据但避免重复。
- 验证：类型测试、旧 fixture 加载、无幕但有旧钩子 fixture。

## T2 删除独立开篇钩子分析阶段

- 从分析阶段、进度 UI、单阶段分析/重分析、默认 sections 和导航删除开篇钩子。
- 修改幕分析输出，使序幕直接成为幕分析的一部分。
- 新增 `acts:prologue` section，并与所有 `acts:<id>` 进入同一 pages 数组和 turn.js 实例。
- 验证：分析请求中无 openingHook 阶段；新旧项目序幕只显示一次；目录可跳转。

## T3 AI 人物/Boss/怪物双集合

- 人物索引与详情输出 `people` 和 `monsters`。
- 人类 Boss 标记 `isBoss`；非人怪物进入 monsters。
- 两集合分别批处理、normalize、merge，再执行跨集合去重。
- 只把原文数值标为 source，推断值标为 inference。
- 验证：人类 Boss 留在人物且被章节引用；怪物不混入人物；重复名称/别名被归并。

## T4 怪物与 Boss 章节

- 在人物与人物经历之间插入 `stage-monsters`。
- 汇总 `people.isBoss` 引用和 monsters；空集合显示空状态。
- 复用核心人物卡规格和 overview/details/stats 语义分页。
- 支持名称打开资料卡、图片区域和编辑入口。
- 验证：人类 Boss 无复制；所有怪物/Boss 字段、CoC、技能、攻击可见且不拦腰切断。

## T5 统一怪物资料卡与覆盖数据

- 浮动资料卡支持 monster 字段、关系、图片、CoC、技能、攻击。
- 人类 Boss 仍打开 person 资料卡。
- 复用 EntityOverrides；KP 私密信息不写入公开字段。
- 验证：刷新后覆盖保留；多资料卡并存；相关实体可继续打开新窗口。

## T6 羊皮纸卡片编辑覆盖层

- 从现有实体窗口抽取/复用 `EntityEditForm`。
- 核心人物、Boss、怪物卡的编辑按钮打开 turn.js 外单例覆盖层。
- 保存后一次写覆盖层、重新分页并恢复逻辑页；取消/Esc 不写入。
- 验证：标题、图片、字段、CoC、技能、攻击均可编辑；书页和资料卡即时一致；重新分析不覆盖 KP 修改。

## T7 书页自适应缩放

- 工作区改用 `100dvh` grid/flex 剩余空间布局。
- 在 `stage-view.tsx` 的 `useTurnBook` 使用 ResizeObserver。
- 固定 680×1150 逻辑分页；同模式调用 size，跨单双页断点才重建。
- 保存并恢复 section/逻辑页，太小显示提示。
- 验证：resize、侧栏切换、离开返回、目录跳转和按钮/键盘翻页均稳定。

## T8 浮动资料卡自适应缩放

- 固定资料卡逻辑尺寸与分页容量，按工作台计算 scale。
- 缩放标题、正文、图片和控件；位置在 resize 后 clamp。
- 保持拖动、置顶、关闭、翻页及多窗口各自状态。
- 验证：不同桌面尺寸与侧栏状态下卡片完整可操作，多窗口不消失。

## T9 集成与交付

- 补齐自动测试：序幕迁移、怪物分类/去重、人类 Boss 引用、语义分页、覆盖层取消/保存、逻辑页恢复。
- 按 `V0.9-checklist.md` 手动验证。
- 运行 `npm run lint`、`npm run build`、`npm run test`。
- 生成 `docs/V0.9-handoff-accept.md`，记录改动、证据、已知问题和 commit。
