## 版本定位

v0.9.0 将项目从“分析结果阅读器”推进为可持续维护的守秘人备本工作台。本版本完成怪物与 Boss 数据模型、核心卡统一规格、序幕归入幕结构、书页等比缩放以及资料卡编辑体验，是后续 v0.9.x 补丁的功能基线。

## 主要内容

### 1. 序幕与幕结构统一

- 删除独立“开篇钩子”分析阶段。
- 开篇内容作为序幕进入“幕”分析与同一书页数组。
- 兼容旧项目的开篇钩子数据，但不重复显示。

### 2. 怪物与 Boss 数据模型

- 有姓名的人类或类人 Boss 继续使用人物实体，并标记 `isBoss`。
- 非人怪物、神话生物、野兽和无名敌人模板使用 monster 实体。
- 怪物和 Boss 均采用核心人物卡规格，支持 CoC 数据、图片与编辑。
- 人类 Boss 在人物与怪物/Boss 章节中引用同一实体，不复制数据。

### 3. 书页与资料窗口缩放

- 保持固定逻辑页尺寸，通过显示缩放适配窗口。
- 同一单双页模式下改变窗口尺寸不重建 turn.js。
- 跨单双页断点时重建实例并恢复逻辑页。
- 浮动资料窗口按可用空间缩放，保留分页、拖动和层级。

### 4. 编辑体验

- 人物卡、怪物卡与实体资料编辑统一使用 turn.js 外的羊皮纸模态层。
- 避免把表单节点加入书页测量克隆和翻页 DOM。
- 删除旧版“应用 v0.8 模板”入口。
