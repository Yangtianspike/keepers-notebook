## 版本主题

人物关系工作台、实体编辑和可视化文档目录完善。

## 修复与新增

### F1 人物关系视图

- 核心人物关系图移动到完整工作区。
- 每个人物资料卡可打开只包含当前人物直接关系的独立窗口。
- 关系窗口采用 React Flow，支持缩放、关闭和打开相关实体。
- 修复方向混乱和循环折线，关系改为清晰直线并标记反向语义。
- 仅关系图窗口支持鼠标自由调整大小。

### F2 实体编辑

- 核心人物及其他资料卡编辑改为分页式编辑界面。
- 扩大文本编辑区域，改善长内容的字体与排版。
- 人物级别修改提供确认提示，并同步更新人物章节和关系图。
- 怪物/Boss 卡补齐关系入口，与核心人物卡功能保持一致。

### F3 可视化文档目录

- 删除编辑器顶部拥挤的横向章节按钮。
- 增加左侧实时目录。
- 用户新增 H1—H6 标题后立即出现在目录中。
- 点击目录标题可定位到当前编辑文档的对应位置。
