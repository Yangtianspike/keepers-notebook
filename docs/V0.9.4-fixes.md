## 版本主题

PDF/DOCX 文档兼容与模型 JSON 输出恢复。

## 修复与新增

### F1 PDF 书签

- PDF 解析器读取内置 Outline/书签，不再只扫描正文标题。
- 书签优先作为章节来源，正文标题用于补充和无书签兜底。
- 已导入项目可在“确认章节结构”点击“重新读取 PDF 书签”。
- 损坏的单个书签目标不会阻止其他书签读取。

### F2 模型 JSON 容错

- 统一服务端和客户端 JSON 解析。
- 本地修复代码围栏、正文包裹、字符串内换行、中文弯引号和尾随逗号。
- 无法修复时保留明确错误，等待用户主动重试，不自动产生额外模型费用。

### F3 DOCX 原始资料

- 原始 Word 文档按 HTML 还原基本标题、段落、表格和内嵌图片。
- DOCX 图片可以提取到图片资料库并加入调查员资料包。
- 使用无脚本 iframe 隔离渲染后的 Word 内容。

### F4 文案

- 截图粘贴提示改为通用“截图工具”，不再绑定具体软件。
