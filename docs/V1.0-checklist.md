# 守秘人笔记本 v1.0.0 验收清单

> 面向独立验收 agent 与用户。逐项实际操作并记录证据，不以代码存在代替界面结果。

## Markdown 与目录

- [ ] 在一个普通章节中创建 H1–H6，编辑器目录立即显示六级结构。
- [ ] 保存后书页目录显示相同 H1–H6，逐项点击能跳到对应书页。
- [ ] 创建两个同名标题，两个目录项分别跳到正确位置。
- [ ] “幕”始终是一级目录；每一幕是其二级目录，幕内标题从三级开始。
- [ ] 清空或重写第一幕内容后，“幕”根目录仍存在，其他幕不升到根级。

## 编辑会话

- [ ] 修改最后一幕内容并保存，返回包含最后修改标题的书页，而不是第一页。
- [ ] 编辑中进入“前期准备”，返回模组笔记本后仍是编辑模式，章节、滚动位置和草稿保持。
- [ ] 有未保存修改时显示状态；刷新或返回项目首页出现放弃提示。
- [ ] 点击取消并确认后不保存草稿，返回进入编辑器前的阅读位置。
- [ ] 工具栏没有“新增段落”；显示“撤销（Ctrl+Z）”和“恢复撤销（Ctrl+Y）”。

## 实体与关系

- [ ] 未选中文字时点击“新建实体”，可选择类型、输入名称并打开资料卡。
- [ ] 在有效光标处创建实体并启用插入链接，书页中的链接可跳转及打开资料窗口。
- [ ] 创建实体时关联已有实体，双方个人关系图立即出现该关系。
- [ ] 在资料卡中添加已有关系，双方个人关系图立即更新。
- [ ] 修改关系说明后双方图同步；移除关系后双方图同步。
- [ ] 修改或隐藏模型关系后重新分析，KP 处理继续生效。
- [ ] 人物升为核心人物后，人物关系进入核心人物关系图；降级后退出。
- [ ] 核心人物与地点、线索或事件的关系不进入核心人物关系图，但个人关系图仍显示。
- [ ] 同一对人物有多条关系时，核心人物关系图只显示最重要的一条。

## 窗口与回归

- [ ] 核心人物卡编辑窗口可从标题栏拖动，输入框操作不会拖动窗口。
- [ ] 编辑窗口无法完全移出视口，拖动后字段草稿不丢失。
- [ ] turn.js 双页、上下页按钮、键盘翻页、跳页和幕树正常。
- [ ] 七阶段分析、PDF/DOCX/Markdown 原始资料和图片资料正常。
