# 守秘人笔记本 v1.0.0 发布说明

> 状态：候选版，待完整验收

## 正式版重点

- 七阶段剧本分析：故事背景、时间地点、人物、怪物/Boss、人物经历与动机、关键线索安排、幕。
- 模组笔记本统一书页阅读与 Markdown 可视化编辑。
- H1–H6 共用目录模型，各幕稳定归入一级“幕”目录。
- 编辑草稿跨页面保留，保存后返回最后修改章节。
- KP 可主动创建实体、建立语义关系并即时刷新个人关系图。
- 核心人物关系图合并模型关系与 KP 关系，只展示人物之间最重要的关系。
- 核心人物卡编辑窗口可拖动，便于与书页和其他资料窗口并存。
- 支持 PDF、DOCX 与 Markdown 原始资料，以及 PDF/DOCX 图片整理和调查员资料包。
- 支持 OpenAI、Anthropic、Gemini 与 Ollama 四类模型协议。

## 数据兼容

- 旧项目无需重新分析即可使用统一目录与编辑会话。
- 旧有模型人物关系继续读取；KP 新建或修订的关系保存为独立覆盖数据。
- KP 对模型关系的修改或隐藏在重新分析后继续保留。

## 发布门槛

- `npm run lint`、`npm run build`、`npm run test` 全部通过。
- 使用真实 PDF 与 DOCX 完成导入、七阶段分析、书页编辑、目录跳转和图片资料回归。
- 验证创建、修改、删除关系后个人关系图与核心人物关系图即时同步。
- 验证跨页面编辑草稿、取消编辑和保存后定位。
- 独立验收不存在阻塞级问题后，状态改为正式发布。
