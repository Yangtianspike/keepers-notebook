# 守秘人笔记本 v1.0.1 补丁

> 状态：已实现，待提交与界面验收  
> 基线版本：v1.0.0 发布候选

## 版本主题

修复书页编辑器运行时错误与入口定位，并把核心人物资料编辑改为可与工作台同时操作的自由浮动窗口。

## 修复与改进

### F1 编辑器滚动事件空引用

- 修复进入或操作 Markdown 书页编辑器时出现 `Cannot read properties of null (reading 'scrollTop')` 的运行时错误。
- 根因是 React 状态更新回调延后执行时，事件对象的 `currentTarget` 已被释放。
- 滚动位置与输入值现在会在事件回调内立即复制，再交给状态更新函数处理。
- 同步检查并修复幕编辑、实体资料编辑和图片资料命名中的同类事件引用，避免相同问题在其他编辑入口复现。

### F2 编辑书页入口定位

- 点击“编辑书页”时，以当前阅读书页的章节作为编辑器初始章节，不再固定打开“故事背景”。
- 当前书页存在可识别标题时，编辑器继续定位到该标题。
- 当前书页没有标题时，回退到当前章节的第一个标题。
- 人物、时间地点、怪物/Boss、人物经历、关键线索和各幕均使用相同的定位逻辑。
- 初始化编辑会话时同步展开目标标题的父级目录，避免目标标题处于折叠目录中。

### F3 核心人物自由编辑窗口

- 核心人物资料编辑由全屏模态框改为非模态浮动窗口。
- 移除全屏黑色遮罩和背景交互拦截。
- 编辑期间仍可操作书页、翻页工具栏、左侧菜单及其他资料窗口。
- 编辑窗口可通过标题栏自由拖动，并可用鼠标调整宽度和高度。
- 浏览器或窗口尺寸变化后会自动保持编辑窗标题栏可见。
- 切换工作台页面不会自动关闭编辑窗，尚未保存的表单草稿继续保留。
- 对话框语义改为 `aria-modal="false"`，与非阻塞行为保持一致。

## 手动验收建议

- 在人物章节翻到任意核心人物所在书页，点击“编辑书页”，确认编辑器直接打开人物章节并定位当前标题。
- 快速滚动可视化编辑器和 Markdown 源码编辑器，确认不再出现 `scrollTop` 空引用。
- 打开核心人物编辑窗后，依次操作翻页、左侧目录和另一个资料窗口，确认互不阻塞。
- 拖动并缩放核心人物编辑窗，确认字段草稿不丢失且窗口标题栏不会完全移出屏幕。
